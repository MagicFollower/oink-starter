> 一条主线八站供通读，十个主题篇供查阅；进度、前置与产出物写在每篇开头。

---

LLMS 索引： [llms.txt](/llms.txt)

---

这个库走双轨：**主线八站**是同一个 Spring Boot + Vue3 项目从「本机跑不起来」演进到「出事能查、查完留痕」的通读路线，**十个主题篇**是按读者认知顺序排列的查阅路线。两者不是两份内容——每篇文章开头都标了自己挂在第几站、前置是哪几章、读完手上多什么。结构以《Docker知识库内容结构与组织清单》v2.1 为唯一依据；本库没有多版本分叉，涉及的版本号、体积、耗时一律在篇内标 as-of 日期并给现查命令。

本节页面：

- [导读](/docs/00-%E5%AF%BC%E8%AF%BB/): 站在入口：双轨怎么读、八站地图、环境准备，以及这个库的写作规矩。
- [基础认知](/docs/01-%E5%9F%BA%E7%A1%80%E8%AE%A4%E7%9F%A5/): 先知道容器解决的是什么问题，再亲手跑起第一个容器。
- [核心操作](/docs/02-%E6%A0%B8%E5%BF%83%E6%93%8D%E4%BD%9C/): 主线站①的日常命令面：把容器跑起来、看住它、连上网、留住数据。
- [镜像构建](/docs/03-%E9%95%9C%E5%83%8F%E6%9E%84%E5%BB%BA/): 主线站③④⑤：从第一份 Dockerfile，到别人也能 build、能拉。
- [单机编排](/docs/04-%E5%8D%95%E6%9C%BA%E7%BC%96%E6%8E%92/): 主线站②：把九参数的 docker run 变成一条 compose up。
- [原理深入](/docs/05-%E5%8E%9F%E7%90%86%E6%B7%B1%E5%85%A5/): 按需查阅层：不要求通读，每篇开头的触发条件告诉你什么时候该来。
- [工程化与生产](/docs/06-%E5%B7%A5%E7%A8%8B%E5%8C%96%E4%B8%8E%E7%94%9F%E4%BA%A7/): 团队尚在本地开发阶段，本篇按「上生产前的准入基线 + 演练」写，不假装有生产事故。
- [运维手册](/docs/07-%E8%BF%90%E7%BB%B4%E6%89%8B%E5%86%8C/): 使用频率最高的一篇，故障域各节一律按「症状 → 判据 → 命令 → 根因」四列写。
- [生态与附录](/docs/08-%E7%94%9F%E6%80%81%E4%B8%8E%E9%99%84%E5%BD%95/): 坐标与查阅件：什么时候该换工具，以及版本口径以谁为准。
- [常见问题](/docs/09-%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98/): 压在全库最后：每条按「问题—机制—数字/命令—自查动作」四段作答，并指回正文判据。
