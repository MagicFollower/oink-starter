{{- /* 侧边栏根选择器 — 条目组装器 【存在意义】 将全局根节点集合（root-menu-roots）与当前页面的实际根节点合并， 输出下拉卡片列表所需的 entries 和 current 两个字段。 root-menu-roots.html 负责「收集候选」，本文件负责「确定当前项 + 置顶排序 + 兜底补录」。 【工作流程】 1. 从缓存的 root-menu-roots 获取全局候选条目（全站顶级栏目 + sidebar_root_for:self 页面） 2. 通过 sidebar-root.html 解析当前页面的实际根节点 3. 兜底补录：若当前根节点不在候选列表中，将其追加进去 4. 置顶排序：将当前页面对应的根节点移到列表最上方，其余条目保持原有排序 5. 返回 { entries, current } 供 root-menu.html 渲染下拉卡片 【解决的问题】 主题原版按固定 weight 排序输出根节点，当前页面所在的区域可能排在列表末尾 （如在博客区域时，「博客」排在笔记的 10 个子分类之后），读者需要在长列表中 查找自己的位置。本覆盖文件将当前根节点始终置于列表首位，读者打开下拉即可 确认所在区域，再浏览其他可选区域。 【放置位置】 站点 layouts/ 目录优先于主题 oink-main/ 目录，因此本文件会自动覆盖主题同名 partial， 无需修改主题源码。 */ -}} {{- $page := . -}} {{- $entries := partialCached "shell/root-menu-roots.html" $page.Site $page.Site.Language.Lang $page.Site.Home.RelPermalink -}} {{- $current := partial "shell/sidebar-root.html" $page -}} {{- if and $current (not $current.IsHome) (not (in $entries $current)) -}} {{- $entries = $entries | append $current -}} {{- end -}} {{- /* 把当前根节点移到列表最上方，其余条目保持原有顺序 */ -}} {{- if $current -}} {{- $top := slice -}} {{- $rest := slice -}} {{- range $entries -}} {{- if eq . $current -}} {{- $top = $top | append . -}} {{- else -}} {{- $rest = $rest | append . -}} {{- end -}} {{- end -}} {{- $entries = $top -}} {{- range $rest -}} {{- $entries = $entries | append . -}} {{- end -}} {{- end -}} {{- return (dict "entries" $entries "current" $current) -}}
