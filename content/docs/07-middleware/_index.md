学习 Java 后端开发中常用的中间件技术。

## 知识板块

- **消息队列** — Kafka、RabbitMQ、RocketMQ 对比与实战
- **Redis** — 数据结构、持久化、集群、缓存策略、分布式锁
- **Elasticsearch** — 倒排索引、DSL 查询、映射优化
- **Nginx** — 反向代理、负载均衡、动静分离
- **注册中心** — Nacos、Consul、ZooKeeper 对比
