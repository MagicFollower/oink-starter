使用频率最高的一篇，故障域各节一律按「症状 → 判据 → 命令 → 根因」四列写。

## 知识板块

- **检索与规矩** — 先找到该看哪一节。
- **按故障域排错** — 起不来、通不了、撑满、拿不到，以及值班时敲的第一条命令。
