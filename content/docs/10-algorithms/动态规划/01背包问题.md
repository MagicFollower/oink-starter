# 为什么需要 01 背包？

想象你要去旅行，行李箱容量 19 公斤。你有 5 件物品可选：

| 物品 | 重量 | 价值 | 「性价比」 |
|------|------|------|----------|
| 0 | 1 kg | 1 分 | 1.0 |
| 1 | 2 kg | 6 分 | 3.0 ← 最高 |
| 2 | 5 kg | 18 分 | 3.6 ← 最高 |
| 3 | 6 kg | 22 分 | 3.7 |
| 4 | 7 kg | 28 分 | 4.0 ← 最高 |

**问题**：怎么选才能让行李箱里的总价值最大？

- **方案 A（暴力枚举）**：每件物品「选」或「不选」，5 件物品有 2⁵ = 32 种组合 → 物品多了就爆炸
- **方案 B（贪心）**：按性价比排序，优先选性价比高的 → 但不一定最优
- **方案 C（动态规划）**：把大问题拆成小问题，逐步决策 → 保证最优

> ### 💡 新人小结：什么是动态规划？
>
> 动态规划就像「爬楼梯」：
> - 你站在第 0 阶，要想到达第 n 阶
> - 每次只能选择「跨 1 阶」或「跨 2 阶」
> - 要想到达第 n 阶，先要知道到达第 n-1 阶和第 n-2 阶的最优方法
>
> 01 背包也一样：对于每件物品，你的选择只有「放」或「不放」——然后看哪种选择让剩余空间的价值最大。

**学习路线图**：

```
状态定义 → 转移方程 → 代码实现 → 空间优化
dp[i][j]  选 or 不选？  自底向上/自顶向下  一维数组
```

---

## 问题定义

给定 n 件物品和一个容量为 W 的背包。每件物品有重量 w[i] 和价值 v[i]，**每件物品只能选择放入或不放入（0 或 1）**。问：如何选择物品使得背包中物品的总价值最大？

**形式化描述**：

- 输入：物品重量数组 `w[]`、价值数组 `v[]`、背包容量 `W`
- 输出：最大总价值
- 约束：每件物品最多选一次，总重量不超过 W

**示例**：

| 物品 | 重量 w | 价值 v |
|------|--------|--------|
| 0 | 1 | 1 |
| 1 | 2 | 6 |
| 2 | 5 | 18 |
| 3 | 6 | 22 |
| 4 | 7 | 28 |

背包容量 W = 19，最大价值 = 65（选物品 1, 2, 3, 4，总重量 2+5+6+7=20... 实际需计算）。

## 状态定义与转移方程

### 痛点引入

动态规划最难的部分不是写代码，而是**定义状态**和**推导转移方程**。

> ### 💡 新人小结：dp[i][j] 是什么意思？
>
> 把 dp 表想象成一个「决策表」：
> - 行：考虑前 i 件物品
> - 列：背包容量为 j
> - 单元格 dp[i][j]：在这种条件下能获得的最大价值
>
> 填表的过程就是「逐步做决策」：每新增一件物品，对每个容量值重新计算「放还是不放更划算」。

### 状态定义

`dp[i][j]` = 考虑前 i 件物品、背包容量为 j 时能获得的最大价值。

### 状态转移方程

对于第 i 件物品（重量 `w[i-1]`，价值 `v[i-1]`）：

- **不放入**：`dp[i][j] = dp[i-1][j]`（继承前 i-1 件的结果）
- **放入**（当 `j >= w[i-1]`）：`dp[i][j] = dp[i-1][j - w[i-1]] + v[i-1]`

取两者的最大值：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j - w[i-1]] + v[i-1])    当 j >= w[i-1]
dp[i][j] = dp[i-1][j]                                        当 j < w[i-1]
```

### 边界条件

- `dp[0][j] = 0`：没有物品可选，价值为 0
- `dp[i][0] = 0`：背包容量为 0，价值为 0

## 自底向上实现（迭代法）

```java
public static int knapsackBottomUp(int[] w, int[] v, int capacity) {
    int n = w.length;
    int[][] dp = new int[n + 1][capacity + 1];

    // 逐行填充 DP 表
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= capacity; j++) {
            if (w[i - 1] <= j) {
                dp[i][j] = Math.max(dp[i - 1][j],
                                    dp[i - 1][j - w[i - 1]] + v[i - 1]);
            } else {
                dp[i][j] = dp[i - 1][j];
            }
        }
    }
    return dp[n][capacity];
}
```

## 自顶向下实现（记忆化递归）

```java
public static int knapsackTopDown(int[] w, int[] v, int capacity) {
    int n = w.length;
    int[][] dp = new int[n + 1][capacity + 1];
    return solve(dp, w, v, n, capacity);
}

private static int solve(int[][] dp, int[] w, int[] v, int i, int cap) {
    // 边界：没有物品或容量为 0
    if (i == 0 || cap == 0) return 0;
    // 已计算过则直接返回
    if (dp[i][cap] != 0) return dp[i][cap];

    if (w[i - 1] <= cap) {
        dp[i][cap] = Math.max(
            solve(dp, w, v, i - 1, cap),
            solve(dp, w, v, i - 1, cap - w[i - 1]) + v[i - 1]
        );
    } else {
        dp[i][cap] = solve(dp, w, v, i - 1, cap);
    }
    return dp[i][cap];
}
```

## 回溯选中的物品列表

从 `dp[n][W]` 反向追踪，判断每件物品是否被选中：

```java
public static List<Integer> traceSelectedItems(int[][] dp, int[] w, int capacity) {
    List<Integer> selected = new ArrayList<>();
    int n = dp.length - 1;
    int cap = capacity;
    for (int i = n; i > 0; i--) {
        if (dp[i][cap] != dp[i - 1][cap]) {
            // 说明第 i 件物品被选中
            selected.add(i - 1);
            cap -= w[i - 1];
        }
    }
    // 反转使顺序与原始数组一致
    java.util.Collections.reverse(selected);
    return selected;
}
```

## 空间优化：一维数组

### 痛点引入

二维 DP 表需要 n × W 的空间。当 n = 1000, W = 10000 时，需要 1000 万个 int（40MB）。

**优化思路**：观察发现 `dp[i][j]` 只依赖 `dp[i-1][...]`，所以只需要保存「上一行」的数据。

观察状态转移方程：`dp[i][j]` 只依赖 `dp[i-1][...]`，因此可以用一维数组滚动更新。

**关键**：内层循环必须**逆序**遍历，防止同一物品被重复选取。

```java
public static int knapsack1D(int[] w, int[] v, int capacity) {
    int n = w.length;
    int[] dp = new int[capacity + 1];

    for (int i = 0; i < n; i++) {
        // 逆序遍历：保证每件物品只选一次
        for (int j = capacity; j >= w[i]; j--) {
            dp[j] = Math.max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[capacity];
}
```

> **为什么逆序？** 如果正序遍历，`dp[j - w[i]]` 可能已经被当前物品更新过，导致同一物品被多次选取——这就变成了**完全背包**问题。

## 完整测试

```java
public static void main(String[] args) {
    int[] weights = {1, 2, 5, 6, 7};
    int[] values  = {1, 6, 18, 22, 28};
    int capacity  = 19;

    // 自底向上
    int maxVal1 = knapsackBottomUp(weights, values, capacity);
    System.out.println("自底向上最大价值: " + maxVal1);

    // 自顶向下
    int maxVal2 = knapsackTopDown(weights, values, capacity);
    System.out.println("自顶向下最大价值: " + maxVal2);

    // 一维数组
    int maxVal3 = knapsack1D(weights, values, capacity);
    System.out.println("一维数组最大价值: " + maxVal3);

    // 回溯选中的物品
    int n = weights.length;
    int[][] dp = new int[n + 1][capacity + 1];
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= capacity; j++) {
            if (weights[i - 1] <= j) {
                dp[i][j] = Math.max(dp[i - 1][j],
                                    dp[i - 1][j - weights[i - 1]] + values[i - 1]);
            } else {
                dp[i][j] = dp[i - 1][j];
            }
        }
    }
    List<Integer> selected = traceSelectedItems(dp, weights, capacity);
    System.out.println("选中的物品索引: " + selected);
    int totalWeight = 0, totalValue = 0;
    for (int idx : selected) {
        System.out.printf("  物品 %d: 重量=%d, 价值=%d%n", idx, weights[idx], values[idx]);
        totalWeight += weights[idx];
        totalValue += values[idx];
    }
    System.out.printf("总重量: %d, 总价值: %d%n", totalWeight, totalValue);
}
```

## 复杂度分析

| 实现方式 | 时间复杂度 | 空间复杂度 |
|---------|-----------|-----------|
| 自底向上（二维 DP） | O(n × W) | O(n × W) |
| 自顶向下（记忆化递归） | O(n × W) | O(n × W) + 递归栈 |
| 一维数组优化 | O(n × W) | O(W) |

> n 为物品数量，W 为背包容量。

## 扩展：背包问题家族

| 变体 | 约束差异 | 代码差异 |
|------|---------|---------|
| **01 背包** | 每件物品最多选 1 次 | 内层逆序遍历 |
| **完全背包** | 每件物品可选无限次 | 内层正序遍历 |
| **多重背包** | 每件物品有数量上限 | 内层正序 + 数量限制 |
| **混合背包** | 部分物品有数量限制，部分无限制 | 按物品类型分别处理 |

# 要点总结

1. **状态转移**是核心：`max(不选, 选)` 的二选一决策
2. **自底向上**更直观，**自顶向下**更容易理解递归关系
3. **一维优化**将空间从 O(nW) 降到 O(W)，但必须逆序遍历
4. **回溯选中物品**：从 dp 表反向追踪 `dp[i][j] != dp[i-1][j]`
5. **完全背包**只需将内层循环改为正序——这是面试常考的对比点
