# 为什么需要二分查找？

想象你在一本 **1000 页的字典** 里查单词 "oink"——你会怎么做？

- **方案 A（线性查找）**：从第 1 页开始，一页一页翻……最坏要翻 1000 次
- **方案 B（二分查找）**：翻开中间（第 500 页），发现 "oink" 在后面 → 只看 501~1000 页 → 再翻中间（第 750 页）……**最多只需翻 10 次**

这就是二分查找的核心威力：**每次砍掉一半的搜索范围**。

| 数据规模 n | 线性查找最坏次数 | 二分查找最坏次数 |
|-----------|----------------|----------------|
| 100 | 100 | 7 |
| 10,000 | 10,000 | 14 |
| 1,000,000 | 1,000,000 | 20 |
| 1,000,000,000 | 1,000,000,000 | 30 |

> ### 💡 新人小结：什么是 O(log n)？
>
> 把 log n 想象成「切蛋糕」：一块蛋糕，每次从中间切一刀，切几刀能切到只剩碎屑？
> 1000 层的蛋糕，切 10 刀就够了——这就是 log₂1000 ≈ 10 的含义。
> 二分查找就是这把刀：每比较一次，搜索范围减半，所以 n 再大也不怕。

**学习路线图**：

```
算法思想 → 三种边界写法（核心） → 迭代/递归实现 → 变体查找
为什么快？  区间定义决定一切     动手写一遍     findFirst/Last
```

## 算法思想

二分查找（Binary Search）针对**有序数组**，每次取中间元素与目标值比较，将搜索范围缩小一半，从而在 O(log n) 时间内完成查找。

核心前提：数组必须有序。

**查找过程可视化**（在 `[1, 3, 5, 7, 9, 11, 13, 15]` 中查找 `7`）：

```
第 1 步：l=0, h=7           mid=3 → arr[3]=7 ✓ 找到！
         ┌──┬──┬──┬──┬──┬──┬──┬──┐
         │ 1│ 3│ 5│ 7│ 9│11│13│15│
         └──┴──┴──┴──┴──┴──┴──┴──┘
                   ↑ mid

在 [1, 3, 5, 7, 9, 11, 13] 中查找 6（不存在）：

第 1 步：l=0, h=6           mid=3 → arr[3]=5 < 6 → l=mid+1=4
         ┌──┬──┬──┬──┬──┬──┬──┐
         │ 1│ 3│ 5│ 7│ 9│11│13│
         └──┴──┴──┴──┴──┴──┴──┘
                   ↑ mid

第 2 步：l=4, h=6           mid=5 → arr[5]=11 > 6 → h=mid-1=4
                     ┌──┬──┬──┐
                     │ 9│11│13│
                     └──┴──┴──┘
                        ↑ mid

第 3 步：l=4, h=4           mid=4 → arr[4]=9 > 6 → h=mid-1=3
                     ┌──┐
                     │ 9│
                     └──┘
                     ↑ mid

第 4 步：l=4 > h=3 → 循环结束，返回 -1（未找到）
```

## 三种边界写法对比

### 痛点引入

二分查找的思想很简单（每次砍半），但**实际编码时 90% 的 bug 出在边界上**：

- `while` 里写 `l < h` 还是 `l <= h`？
- 没找到时 `h = mid` 还是 `h = mid - 1`？
- 为什么有人用 `l <= h`，有人用 `l < h`？

> ### 💡 新人小结：三种写法到底在干什么？
>
> 把查找区间想象成一段**绳子**：
> - **左闭右闭 `[l, h]`**：绳子的两端都包含在内。当 `l > h` 时绳子不存在 → 条件是 `l <= h`
> - **左闭右开 `[l, h)`**：左端包含，右端不包含（像 Java 的 `substring`）。当 `l == h` 时区间为空 → 条件是 `l < h`
> - **左开右开 `(l, h)`**：两端都不包含，需要至少隔一个元素 → 条件是 `l + 1 < h`
>
> **新手建议**：先熟练掌握**左闭右闭**这一种写法，其他写法等熟练后再扩展。

二分查找的难点在于区间边界的定义。不同写法决定了 `while` 条件和 `mid ± 1` 的调整方式。

| 写法 | 区间含义 | while 条件 | 收缩方式 |
|------|---------|-----------|---------|
| 左闭右闭 `[l, h]` | 两端都包含 | `l <= h` | `l = mid + 1` / `h = mid - 1` |
| 左闭右开 `[l, h)` | 左含右不含 | `l < h` | `l = mid + 1` / `h = mid` |
| 左开右开 `(l, h)` | 两端都不含 | `l + 1 < h` | `l = mid` / `h = mid` |

> 最常用的是**左闭右闭**写法，下面的实现以此为基准。

## 迭代实现（左闭右闭）

```java
public static int binarySearch(int[] arr, int key) {
    if (arr == null || arr.length == 0) return -1;
    int l = 0, h = arr.length - 1;
    while (l <= h) {
        int mid = (l + h) >>> 1;    // 无符号右移，防止溢出
        if (arr[mid] < key) {
            l = mid + 1;
        } else if (arr[mid] > key) {
            h = mid - 1;
        } else {
            return mid;
        }
    }
    return -1;
}
```

**中点计算要点**：

- `(l + h) / 2`：当 `l + h` 超过 `Integer.MAX_VALUE` 时会溢出为负数
- `(l + h) >>> 1`：无符号右移 1 位，等价于除以 2 但不会溢出（JDK 推荐写法）
- `l + (h - l) / 2`：另一种防溢出写法

## 递归实现

```java
public static int binarySearchRecursive(int[] arr, int key) {
    if (arr == null || arr.length == 0) return -1;
    return search(arr, 0, arr.length - 1, key);
}

private static int search(int[] arr, int l, int h, int key) {
    if (l > h) return -1;
    int mid = (l + h) >>> 1;
    if (arr[mid] < key) {
        return search(arr, mid + 1, h, key);
    } else if (arr[mid] > key) {
        return search(arr, l, mid - 1, key);
    } else {
        return mid;
    }
}
```

## 变体：查找第一个 / 最后一个等于给定值的元素

当数组中存在重复元素时，普通二分查找只返回其中一个匹配位置。以下变体可定位边界：

### 查找第一个等于 key 的位置

```java
public static int findFirst(int[] arr, int key) {
    int l = 0, h = arr.length - 1;
    int result = -1;
    while (l <= h) {
        int mid = (l + h) >>> 1;
        if (arr[mid] < key) {
            l = mid + 1;
        } else if (arr[mid] > key) {
            h = mid - 1;
        } else {
            result = mid;     // 记录当前位置
            h = mid - 1;      // 继续向左搜索，看是否还有更早出现的
        }
    }
    return result;
}
```

### 查找最后一个等于 key 的位置

```java
public static int findLast(int[] arr, int key) {
    int l = 0, h = arr.length - 1;
    int result = -1;
    while (l <= h) {
        int mid = (l + h) >>> 1;
        if (arr[mid] < key) {
            l = mid + 1;
        } else if (arr[mid] > key) {
            h = mid - 1;
        } else {
            result = mid;     // 记录当前位置
            l = mid + 1;      // 继续向右搜索，看是否还有更晚出现的
        }
    }
    return result;
}
```

**示例**：

```java
public static void main(String[] args) {
    int[] arr = {1, 2, 2, 2, 3, 4, 5};
    System.out.println(findFirst(arr, 2));  // 1
    System.out.println(findLast(arr, 2));   // 3
}
```

## 完整测试

```java
public static void main(String[] args) {
    int[] arr = {1, 3, 5, 7, 9, 11, 13, 15};

    // 基本查找
    System.out.println(binarySearch(arr, 7));    // 3
    System.out.println(binarySearch(arr, 1));    // 0
    System.out.println(binarySearch(arr, 15));   // 7
    System.out.println(binarySearch(arr, 6));    // -1

    // 递归查找
    System.out.println(binarySearchRecursive(arr, 9));  // 4

    // 变体查找
    int[] dup = {1, 2, 2, 2, 3, 4};
    System.out.println(findFirst(dup, 2));  // 1
    System.out.println(findLast(dup, 2));   // 3
}
```

## 复杂度分析

| 指标 | 值 |
|------|-----|
| 时间复杂度（最好） | O(1) — 第一次就命中 |
| 时间复杂度（最坏） | O(log n) |
| 时间复杂度（平均） | O(log n) |
| 空间复杂度（迭代） | O(1) |
| 空间复杂度（递归） | O(log n) — 递归调用栈 |

## 与线性查找对比

| 对比项 | 线性查找 | 二分查找 |
|--------|---------|---------|
| 数据要求 | 无序即可 | 必须有序 |
| 时间复杂度 | O(n) | O(log n) |
| 数据结构 | 数组、链表均可 | 仅数组（需随机访问） |
| 适用场景 | 数据量小、频繁插入删除 | 数据量大、查询密集 |

## JDK 参考

`java.util.Arrays.binarySearch()` 是 JDK 内置的二分查找方法：

```java
int[] arr = {1, 3, 5, 7, 9};
int index = Arrays.binarySearch(arr, 7);  // 返回 3
```

其实现要点：
- 使用 `(low + high) >>> 1` 防溢出
- 找到目标返回索引，未找到返回 `-(插入点) - 1`
- 对大数组（> 80 元素）使用二分查找，小数组退化为线性查找

# 要点总结

1. **前提条件**：数组必须有序，否则结果无意义
2. **防溢出**：中点计算使用 `>>> 1` 而非 `/ 2`
3. **边界一致性**：`while` 条件和区间收缩必须与边界定义匹配
4. **变体应用**：通过 `result` 记录 + 继续收缩方向，可定位重复元素的边界
5. **局限性**：仅适用于数组，不适用于链表（无法 O(1) 随机访问）

---

> ### 💡 新人小结：二分查找学完了，记住这 4 点
>
> 1. **前提**：数组必须有序。无序数组先排序再查找
> 2. **防溢出**：`mid = (l + h) >>> 1` 是 JDK 标准写法，别用 `(l + h) / 2`
> 3. **边界三件套必须统一**：区间定义 → while 条件 → 收缩方式，三者要一致
> 4. **变体查找的核心**：找到目标时不立即返回，而是记录结果 + 继续往左/右搜索
