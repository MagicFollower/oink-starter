# 为什么需要康托展开？

想象你有一本「全排列字典」，里面收录了 `{0, 1, 2, 3}` 的所有 24 种排列，按字典序排列：

```
第  0 个: [0, 1, 2, 3]
第  1 个: [0, 1, 3, 2]
第  2 个: [0, 2, 1, 3]
...
第 23 个: [3, 2, 1, 0]
```

现在有两个问题：
- **问题 A**：给你排列 `[3, 2, 1, 0]`，它是第几个？（正向展开）
- **问题 B**：给你序号 23，对应的排列是什么？（逆向展开）

如果暴力枚举，最坏要遍历所有 24 个排列。但康托展开可以**直接计算**，无需枚举！

> ### 💡 新人小结：康托展开是干什么的？
>
> 康托展开就像「排列的身份证号」：
> - 每个排列都有一个唯一的序号（就像每个人都有唯一的身份证号）
> - 正向展开：已知排列 → 算序号
> - 逆向展开：已知序号 → 还原排列
>
> 生活类比：你在字典里查单词，不用翻遍整本字典才能找到它——直接按字母定位就行。康托展开就是「排列的字典定位算法」。

## 问题定义

康托展开建立了**全排列**与**自然数**之间的双射关系：

- **正向展开**：给定一个排列，求它在所有排列按字典序排列中的索引
- **逆向展开**：给定索引，求对应的排列

例如，对于 `{0, 1, 2, 3}` 的全排列（共 4! = 24 种）：

| 索引 | 排列 |
|------|------|
| 0 | 0, 1, 2, 3 |
| 1 | 0, 1, 3, 2 |
| ... | ... |
| 23 | 3, 2, 1, 0 |

## 康托展开公式

### 核心思想

康托展开的核心是「**逐位确定贡献**」：对于排列的每一位，计算「这一位对总序号的贡献是多少」。

给定排列 `r[0], r[1], ..., r[n-1]`，其展开值为：

```
X = a[n-1] × (n-1)! + a[n-2] × (n-2)! + ... + a[1] × 1! + a[0] × 0!
```

其中 `a[i]` 表示在第 i 位之后、比 `r[i]` 小的**尚未出现过**的元素个数。

**示例**：排列 `{3, 2, 1, 0}`

- 第 0 位 `3`：后面比 3 小的有 `{2, 1, 0}` → a[0] = 3
- 第 1 位 `2`：后面比 2 小的有 `{1, 0}` → a[1] = 2
- 第 2 位 `1`：后面比 1 小的有 `{0}` → a[2] = 1
- 第 3 位 `0`：后面没有元素 → a[3] = 0

展开值 = 3×3! + 2×2! + 1×1! + 0×0! = 18 + 4 + 1 + 0 = **23**

## 正向展开实现（排列 → 序号）

```java
/**
 * 康托正向展开：排列 → 序号
 *
 * @param arr 排列数组（元素为 0 ~ n-1 的整数）
 * @return 该排列在所有排列中的索引（从 0 开始）
 */
public static int canto(int[] arr) {
    if (arr == null || arr.length == 0) return 0;
    int n = arr.length;
    int index = 0;
    for (int i = 0; i < n; i++) {
        int smaller = 0;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[i]) {
                smaller++;
            }
        }
        index += smaller * factorial(n - 1 - i);
    }
    return index;
}
```

## 逆向展开实现（序号 → 排列）

**思路**：逐位确定。对于第 i 位，用 `x / (n-1-i)!` 得到该位应该选第几个未使用的数字。

> ### 💡 新人小结：逆向展开像「发牌」
>
> 想象你有 4 张牌 `[0, 1, 2, 3]`，要按序号发牌：
> 1. 先看序号里有多少个 3! → 确定第一张牌发哪张
> 2. 再看余数里有多少个 2! → 确定第二张牌发哪张
> 3. 以此类推，直到所有牌发完
>
> 就像从大到小「切蛋糕」：先切最大的块，再切次大的，最后切最小的。

**位图标记**：用一个 int 的 bit 位标记哪些数字已被使用。

```java
/**
 * 康托逆向展开：序号 → 排列
 *
 * @param n 排列中元素的个数
 * @param x 目标排列的索引（从 0 开始）
 * @return 对应的排列数组
 */
public static int[] inverseCanto(int n, int x) {
    int[] result = new int[n];
    int used = 0;  // 位图：标记已使用的数字

    for (int i = 0; i < n; i++) {
        int f = factorial(n - 1 - i);
        int a = x / f;    // 该位应选第 a 个未使用的数字
        x = x % f;        // 余数继续处理下一位

        // 在 0 ~ n-1 中找到第 a 个未被使用的数字
        for (int j = 0; j < n; j++) {
            if ((used & (1 << j)) != 0) continue;  // 已使用，跳过
            if (a == 0) {
                used |= (1 << j);  // 标记为已使用
                result[i] = j;
                break;
            }
            a--;
        }
    }
    return result;
}
```

## 阶乘的递归与迭代实现

```java
// 递归实现
public static int factorialRecursive(int n) {
    return n <= 1 ? 1 : n * factorialRecursive(n - 1);
}

// 迭代实现（推荐，无栈溢出风险）
public static int factorial(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}
```

> **0 的阶乘为什么是 1？** 从组合数学角度：0 个元素的排列只有 1 种（空排列），所以 0! = 1。这也是阶乘递推公式 `n! = n × (n-1)!` 在 n=1 时的自然推论：`1! = 1 × 0!` → `0! = 1`。

## 完整测试

```java
public static void main(String[] args) {
    // 正向展开
    int[] arr = {3, 2, 1, 0};
    int index = canto(arr);
    System.out.println("排列 [3,2,1,0] 的序号: " + index);  // 23

    // 逆向展开
    int lastIndex = factorial(4) - 1;  // 23
    int[] result = inverseCanto(4, lastIndex);
    System.out.println("序号 23 对应的排列: " + Arrays.toString(result));  // [3, 2, 1, 0]

    // 验证互逆
    int[] arr2 = {1, 0, 3, 2};
    int idx = canto(arr2);
    System.out.println("排列 [1,0,3,2] 的序号: " + idx);  // 7
    int[] restored = inverseCanto(4, idx);
    System.out.println("序号 " + idx + " 对应的排列: " + Arrays.toString(restored));  // [1, 0, 3, 2]
}
```

## 排列与组合的数学基础

| 概念 | 定义 | 公式 |
|------|------|------|
| 排列 P(n,m) | 从 n 个不同元素中取 m 个排列 | n! / (n-m)! |
| 组合 C(n,m) | 从 n 个不同元素中取 m 个组合 | n! / (m! × (n-m)!) |
| 全排列 P(n,n) | n 个元素的所有排列 | n! |

康托展开本质上是利用全排列的字典序，将排列映射到 0 ~ n!-1 的自然数。

## 应用场景

| 场景 | 说明 |
|------|------|
| 排列哈希 | 将排列压缩为唯一整数，用作哈希表的 key |
| 排列枚举 | 按序号直接生成第 k 个排列，无需枚举前面所有排列 |
| 压缩存储 | n 个元素的排列只需存一个整数（log(n!) bit） |
| 逆序对计算 | 展开过程中的 a[i] 就是逆序对计数 |

## 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 正向展开 | O(n²) | O(1) |
| 逆向展开 | O(n²) | O(n) |

> 内层循环扫描导致 O(n²)。对于大规模 n，可以使用树状数组（BIT）优化到 O(n log n)。

# 要点总结

1. **康托展开**是排列与自然数之间的双射，正向求序号、逆向求排列
2. **核心计算**：每位后面比它小的未出现元素个数 × 对应阶乘
3. **逆向展开**用位图标记已使用的数字，确保每位选到正确的数字
4. **阶乘**推荐迭代实现，避免递归栈溢出
5. 实际应用：排列哈希、第 k 个排列问题、逆序对计数
