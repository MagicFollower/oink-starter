# 为什么需要二叉树？

想象你要整理一个家族的家谱：

```
              爷爷
            /      \
          伯父      父亲
         /  \      /    \
       堂哥  堂姐  我    妹妹
```

这种「一个节点最多有两个分支」的结构，就是**二叉树**。

**二叉树为什么重要？**

| 应用场景 | 二叉树的角色 |
|---------|-------------|
| 数据库索引 | B+ 树（二叉树的多叉扩展）加速查询 |
| HashMap | JDK 8+ 的链表转红黑树（自平衡二叉搜索树） |
| 表达式解析 | `a + b * c` 解析为二叉树，根节点是 `+` |
| 文件系统 | 目录结构就是一棵树 |
| 优先队列 | 堆（完全二叉树）实现 |

> ### 💡 新人小结：什么是二叉树？
>
> 把二叉树想象成一个「分叉路口」：
> - 每个路口（节点）最多有两个方向：左和右
> - 最顶端的路口叫「根」
> - 没有分支的末端叫「叶子」
> - 从根到叶子的路径长度叫「树高」
>
> 就像一棵真的树：树根在最下面（数据结构的树是倒过来的），树枝分叉，叶子在末端。


## 二叉树的定义与性质

二叉树是每个节点**最多有两个子节点**（左子节点、右子节点）的树形结构。

**基本性质**：

- 第 i 层最多有 2^(i-1) 个节点（i ≥ 1）
- 深度为 k 的二叉树最多有 2^k - 1 个节点
- 叶子节点数 = 度为 2 的节点数 + 1（即 n₀ = n₂ + 1）

**特殊二叉树**：

| 类型 | 定义 |
|------|------|
| 满二叉树 | 每层节点数都达到最大值 |
| 完全二叉树 | 除最后一层外，其余层都是满的，且最后一层节点靠左排列 |
| 二叉搜索树（BST） | 左子树所有节点 < 根 < 右子树所有节点 |

## 从层序数组构建二叉树（BFS 建树）

### 痛点引入

在算法题中，二叉树的输入通常是一个「层序数组」。你需要先把它转换成树结构，才能进行后续操作。

层序数组按从上到下、从左到右的顺序排列，`null` 表示空节点。

例如 `[1, 2, 3, null, null, 6, 7]` 构建的二叉树：

```
        1
       / \
      2   3
         / \
        6   7
```

```java
public static TreeNode buildTree(List<Integer> nums) {
    if (nums == null || nums.isEmpty()) return null;
    TreeNode root = new TreeNode(nums.get(0));
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int i = 1;
    while (i < nums.size() && !queue.isEmpty()) {
        TreeNode node = queue.poll();
        // 左子节点
        if (i < nums.size() && nums.get(i) != null) {
            node.left = new TreeNode(nums.get(i));
            queue.offer(node.left);
        }
        i++;
        // 右子节点
        if (i < nums.size() && nums.get(i) != null) {
            node.right = new TreeNode(nums.get(i));
            queue.offer(node.right);
        }
        i++;
    }
    return root;
}
```

## 四种遍历方式

### 痛点引入

二叉树的遍历是**所有树形结构操作的基础**。但四种遍历方式（前序/中序/后序/层序）的名称容易混淆。

> ### 💡 新人小结：四种遍历的名称怎么记？
>
> 「前序/中序/后序」的「前/中/后」指的是**根节点**在什么时候被访问：
> - **前序**（根 → 左 → 右）：根在最**前**面
> - **中序**（左 → 根 → 右）：根在**中**间
> - **后序**（左 → 右 → 根）：根在**后**面
> - **层序**：一层一层从左到右，像拍照一样逐行扫描

### 一、前序遍历（根 → 左 → 右）

**递归实现**：

```java
public static List<Integer> preorderRecursive(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    preorder(root, result);
    return result;
}

private static void preorder(TreeNode node, List<Integer> result) {
    if (node == null) return;
    result.add(node.val);
    preorder(node.left, result);
    preorder(node.right, result);
}
```

**迭代实现**（显式栈）：

```java
public static List<Integer> preorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    if (root == null) return result;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.add(node.val);
        // 先压右再压左（栈是后进先出，保证左子节点先出）
        if (node.right != null) stack.push(node.right);
        if (node.left != null) stack.push(node.left);
    }
    return result;
}
```

### 二、中序遍历（左 → 根 → 右）

**递归实现**：

```java
public static List<Integer> inorderRecursive(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    inorder(root, result);
    return result;
}

private static void inorder(TreeNode node, List<Integer> result) {
    if (node == null) return;
    inorder(node.left, result);
    result.add(node.val);
    inorder(node.right, result);
}
```

**迭代实现**（显式栈）：

```java
public static List<Integer> inorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode curr = root;
    while (curr != null || !stack.isEmpty()) {
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }
        curr = stack.pop();
        result.add(curr.val);
        curr = curr.right;
    }
    return result;
}
```

### 三、后序遍历（左 → 右 → 根）

**递归实现**：

```java
public static List<Integer> postorderRecursive(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    postorder(root, result);
    return result;
}

private static void postorder(TreeNode node, List<Integer> result) {
    if (node == null) return;
    postorder(node.left, result);
    postorder(node.right, result);
    result.add(node.val);
}
```

**迭代实现**（前序变体 + 反转）：

```java
public static List<Integer> postorderIterative(TreeNode root) {
    LinkedList<Integer> result = new LinkedList<>();
    if (root == null) return result;
    Deque<TreeNode> stack = new ArrayDeque<>();
    stack.push(root);
    while (!stack.isEmpty()) {
        TreeNode node = stack.pop();
        result.addFirst(node.val);   // 头插法，等价于最后反转
        if (node.left != null) stack.push(node.left);
        if (node.right != null) stack.push(node.right);
    }
    return result;
}
```

### 四、层序遍历（BFS，逐层从左到右）

**不含 null 的层序遍历**（常规用法）：

```java
public static List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>(size);
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
```

**含 null 的层序遍历**（保留树结构信息）：

```java
public static List<List<Integer>> levelOrderWithNull(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    // 当队列中还有非 null 节点时继续
    while (queue.stream().anyMatch(java.util.Objects::nonNull)) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>(size);
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node != null) {
                level.add(node.val);
                queue.offer(node.left);
                queue.offer(node.right);
            } else {
                level.add(null);
            }
        }
        result.add(level);
    }
    return result;
}
```

## 完整测试

```java
public static void main(String[] args) {
    // 层序数组：[1, 2, 3, null, null, 6, 7]
    List<Integer> nums = Arrays.asList(1, 2, 3, null, null, 6, 7);
    TreeNode root = buildTree(nums);

    System.out.println("前序(递归): " + preorderRecursive(root));   // [1, 2, 3, 6, 7]
    System.out.println("前序(迭代): " + preorderIterative(root));   // [1, 2, 3, 6, 7]
    System.out.println("中序(递归): " + inorderRecursive(root));    // [2, 1, 6, 3, 7]
    System.out.println("中序(迭代): " + inorderIterative(root));    // [2, 1, 6, 3, 7]
    System.out.println("后序(递归): " + postorderRecursive(root));  // [2, 6, 7, 3, 1]
    System.out.println("后序(迭代): " + postorderIterative(root));  // [2, 6, 7, 3, 1]
    System.out.println("层序: " + levelOrder(root));                // [[1], [2, 3], [6, 7]]
}
```

## 复杂度分析

| 遍历方式 | 时间复杂度 | 空间复杂度（递归） | 空间复杂度（迭代） |
|---------|-----------|-----------------|-----------------|
| 前序 | O(n) | O(h) | O(h) |
| 中序 | O(n) | O(h) | O(h) |
| 后序 | O(n) | O(h) | O(h) |
| 层序 | O(n) | — | O(n) |

> h 为树高。最坏情况 h = n（退化为链表），最好情况 h = log n（满二叉树）。

# 要点总结

1. **建树**：层序数组 + BFS 队列是标准建树方式
2. **递归 vs 迭代**：递归简洁但消耗栈空间，迭代用显式栈控制流程
3. **中序遍历**对 BST 产生有序序列，是 BST 的核心操作
4. **层序遍历含 null** 可完整还原树结构，常用于序列化/反序列化
5. **后序遍历迭代**可用「前序变体 + 头插法」简化实现

> ### 💡 新人小结：二叉树学完了，记住这 4 点
>
> 1. **名称记忆**：前/中/后序的「前中后」指的是根节点被访问的顺序
> 2. **递归三行代码**：访问根 → 递归左 → 递归右（前序），只是顺序不同
> 3. **迭代用栈**：递归能做的迭代都能做，用显式栈模拟递归调用
> 4. **层序用队列**：BFS 逐层扫描，适合「按层处理」的场景
