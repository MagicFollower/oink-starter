每篇一个消息类型，按「没有它有多痛苦 → starter 怎么承载这个语义 → 代码与参数怎么写」展开，并把 4.9.8 上压根不成立的写法显式标出来。机制原理链接第 4、5 章，本板块只讲 Spring Boot 侧的落地。

本板块包含：普通消息与三种发送语义；批量消息与整批上限；延时消息与订单超时关单；定时消息与任意时刻投递；顺序消息与分区有序落地；事务消息与半消息回查。
