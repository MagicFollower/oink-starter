本板块系统讲解 Apache Fesod (Incubating)——高性能、低内存的 Java 电子表格读写库，两篇文档组成完整学习路径：

```
核心 API 与实战 → Spring Boot 集成实战
注解/监听器/转换器    上传下载/流式导出/大文件
```

当前最新版本为 **2.0.2-incubating**（要求 JDK 8+），底层基于 Apache POI 5.5.1。本板块所有文档基于该版本编写。
