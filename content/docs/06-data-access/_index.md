掌握 Java 数据持久化方案与事务处理机制。

## 知识板块

- **JDBC** — 连接池、Statement、ResultSet、最佳实践
- **MyBatis** — 映射原理、动态 SQL、插件机制、缓存
- **JPA/Hibernate** — 实体映射、懒加载、N+1 问题、查询优化
- **事务管理** — 声明式事务、传播行为、分布式事务
- **连接池** — HikariCP 配置与调优、Druid 监控
