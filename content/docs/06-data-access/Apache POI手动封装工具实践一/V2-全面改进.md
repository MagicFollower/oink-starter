## 变更总览

| 编号 | 改进项 | 对应 V1 问题 | 变更要点 |
|------|--------|-------------|----------|
| 1 | 修复 7 个 Bug | A1-A7 | XxBaseException 构造函数名修正；StyleSignature 改用完整签名；错误码去重；getMessage 比较修正；BizException message 传 super；文件名无后缀抛异常；copyColumnWidths 判空 |
| 2 | 核心 API 升级 Workbook 接口 | B1 | init/fillData/export 全部使用 `Workbook`/`Sheet`/`Row`/`Cell`/`CellStyle`/`Font` 接口；默认样式方法参数改为 `Workbook`；调用方可传入 `XSSFWorkbook` 获得 xlsx 格式 |
| 3 | fillData 样式智能填充 | B2 | 仅在 Cell 样式索引为 0（未自定义）时才设置默认数据样式，保留调用方的自定义样式 |

| 6 | 抽取 init 公共逻辑 | C1 | 3 个 init 重载统一委托 `doInit()`，消除 6 处重复代码 |

| 9 | 枚举不可变 | B7 | `SysRetCodeConstants` 字段改为 `final`，移除 setter |
| 10 | 日志规范化 | C2 | 去掉 `>>>>>>>>\|...\|<<<<<<<<` 装饰符，使用标准格式 |

    /**
     * 所有 init 重载的最终委托方法
     */
    private static <T> ExcelExportUtils<T> doInit(
            @NonNull Map<String, List<String>> sheetNameToTitlesMap,
            Map<String, List<T>> sheetNameToSheetDataMap,
            @NonNull Workbook workbookInstance,
            Function<Workbook, CellStyle> defaultTitleCellStyleFunction,
            Function<Workbook, CellStyle> defaultDataCellStyleFunction,
            Integer defaultColumnWidth,
            Integer defaultRowHeight) {

        ExcelExportUtils<T> thisUtil = new ExcelExportUtils<>();
        thisUtil.workbook = workbookInstance;
        // 【改进 #4】使用 LinkedHashMap 保证 Sheet 顺序
        thisUtil.sheetNameToSheetMap = new LinkedHashMap<>(sheetNameToTitlesMap.size());
        thisUtil.sheetNameToSheetDataMap = sheetNameToSheetDataMap;

        // 样式初始化（消除 V1 中 6 处重复代码）【改进 #6】
        thisUtil.defaultHeaderCellStyle = (defaultTitleCellStyleFunction != null)
                ? defaultTitleCellStyleFunction.apply(workbookInstance)
                : createDefaultHeaderStyle(workbookInstance);
        thisUtil.defaultDataCellStyle = (defaultDataCellStyleFunction != null)
                ? defaultDataCellStyleFunction.apply(workbookInstance)
                : createDefaultDataStyle(workbookInstance);

        int colWidth = Optional.ofNullable(defaultColumnWidth).orElse(DEFAULT_COLUMN_WIDTH);
        short rowHeight = Optional.ofNullable(defaultRowHeight).orElse(DEFAULT_ROW_HEIGHT_TWIPS).shortValue();

        sheetNameToTitlesMap.forEach((sheetName, titles) -> {
            Sheet sheet = workbookInstance.createSheet(sheetName);
            sheet.setDefaultColumnWidth(colWidth);
            sheet.setDefaultRowHeight(rowHeight);

            Row headerRow = sheet.createRow(0);
            for (int i = 0; i < titles.size(); i++) {
                Cell cell = headerRow.createCell(i);
                cell.setCellValue(titles.get(i));
                cell.setCellStyle(thisUtil.defaultHeaderCellStyle);
            }
            thisUtil.sheetNameToSheetMap.put(sheetName, sheet);
        });

        return thisUtil;
    }

    /**
     * 填充每个 Sheet 的数据
     *
     * @param sheetDataConsumer 两参数消费者：(sheetName→数据集, sheetName→Sheet实例)
     */
    public ExcelExportUtils<T> fillData(
            @NonNull BiConsumer<Map<String, List<T>>, Map<String, Sheet>> sheetDataConsumer) {
        if (sheetNameToSheetDataMap == null) {
            throw new IllegalStateException(
                    "[sheetNameToSheetDataMap] 未初始化，请确认使用了正确的 init() 方法");
        }

        sheetDataConsumer.accept(sheetNameToSheetDataMap, sheetNameToSheetMap);

        // 【改进 #3】样式智能填充：仅在 Cell 未设置自定义样式时才应用默认样式
        for (int sheetIndex = 0; sheetIndex < workbook.getNumberOfSheets(); sheetIndex++) {
            Sheet sheet = workbook.getSheetAt(sheetIndex);
            for (int rowIndex = 1; rowIndex <= sheet.getLastRowNum(); rowIndex++) {
                Row row = sheet.getRow(rowIndex);
                if (row == null) {
                    continue;
                }
                for (int cellIndex = 0; cellIndex < row.getLastCellNum(); cellIndex++) {
                    Cell cell = row.getCell(cellIndex);
                    if (cell != null && cell.getCellStyle().getIndex() == 0) {
                        cell.setCellStyle(defaultDataCellStyle);
                    }
                }
            }
        }
        return this;
    }

    /**
     * 写入 HttpServletResponse（默认开启文件名 URL 编码）
     */
    public void export(@NonNull HttpServletResponse servletResponse, String fileName) {
        String resolvedName = StringUtils.isEmpty(fileName) ? DEFAULT_FILE_NAME : fileName;
        String encodedName = encodeFileName(resolvedName);
        try {
            // 【改进 #5】先 reset 再获取流
            servletResponse.reset();
            servletResponse.setContentType(EXCEL_CONTENT_TYPE);
            servletResponse.setHeader("Content-Disposition", "attachment;filename=" + encodedName);
            OutputStream outputStream = servletResponse.getOutputStream();
            this.workbook.write(outputStream);
            outputStream.flush();
        } catch (IOException e) {
            log.error("导出到 HttpServletResponse 失败: {}", e.getMessage(), e);
            throw new BizException(SysRetCodeConstants.FAILED.getCode(), e.getMessage());
        } finally {
            // 【改进 #5】确保 Workbook 资源释放
            closeWorkbookQuietly();
        }
    }

    /**
     * 写入 OutputStream（流在方法调用后不会关闭）
     */
    public void export(@NonNull OutputStream outputStream) {
        try {
            this.workbook.write(outputStream);
            outputStream.flush();
        } catch (IOException e) {
            log.error("导出到 OutputStream 失败: {}", e.getMessage(), e);
            throw new BizException(SysRetCodeConstants.FAILED.getCode(), e.getMessage());
        } finally {
            closeWorkbookQuietly();
        }
    }

    /**
     * 【改进 #8】文件名编码：正确处理含多个 "." 的文件名
     */
    private static String encodeFileName(String fileName) {
        int lastDotIndex = fileName.lastIndexOf('.');
        if (lastDotIndex <= 0) {
            // 【改进 #1-A6】无后缀时抛异常而非静默返回
            throw new IllegalArgumentException(
                    "文件名必须包含后缀（如 .xls 或 .xlsx），当前文件名: " + fileName);
        }
        String baseName = fileName.substring(0, lastDotIndex);
        String extension = fileName.substring(lastDotIndex);
        try {
            return URLEncoder.encode(baseName, StandardCharsets.UTF_8.name()) + extension;
        } catch (Exception e) {
            return fileName;
        }
    }

    /** 静默关闭 Workbook */
    private void closeWorkbookQuietly() {

                this.workbook.close();
            }
        } catch (IOException e) {
            log.warn("关闭 Workbook 失败: {}", e.getMessage());
        }
    }

    // ==================== Sheet 复制（静态方法，基于 XSSFWorkbook） ====================

    /**
     * 将源 Sheet 完整复制到目标 Workbook 的新 Sheet 中，保留内容、样式、图片
     */
    public static void copySheet(Sheet sourceSheet, XSSFWorkbook targetWorkbook, String newSheetName) {
        XSSFSheet targetSheet = targetWorkbook.createSheet(newSheetName);
        CellStyleCache styleCache = new CellStyleCache(targetWorkbook);

        copyPictures(sourceSheet, targetSheet, targetWorkbook);
        copyMergedRegions(sourceSheet, targetSheet);
        copyColumnWidths(sourceSheet, targetSheet);

        for (int i = sourceSheet.getFirstRowNum(); i <= sourceSheet.getLastRowNum(); i++) {
            Row sourceRow = sourceSheet.getRow(i);
            if (sourceRow == null) {
                continue;
            }
            Row targetRow = targetSheet.createRow(i);
            targetRow.setHeight(sourceRow.getHeight());

            for (int j = sourceRow.getFirstCellNum(); j < sourceRow.getLastCellNum(); j++) {
                Cell sourceCell = sourceRow.getCell(j);
                if (sourceCell == null) {
                    continue;
                }
                Cell targetCell = targetRow.createCell(j);
                copyCell(sourceCell, targetCell, styleCache);
            }
        }
    }

    private static void copyCell(Cell sourceCell, Cell targetCell, CellStyleCache styleCache) {
        if (sourceCell.getCellStyle() != null) {
            CellStyle cachedStyle = styleCache.getOrCreate((XSSFCellStyle) sourceCell.getCellStyle());
            targetCell.setCellStyle(cachedStyle);
        }

        switch (sourceCell.getCellType()) {
            case STRING:
                targetCell.setCellValue(sourceCell.getRichStringCellValue());
                break;
            case NUMERIC:
                if (DateUtil.isCellDateFormatted(sourceCell)) {
                    targetCell.setCellValue(sourceCell.getDateCellValue());
                } else {
                    targetCell.setCellValue(new BigDecimal(
                            String.valueOf(sourceCell.getNumericCellValue()))
                            .stripTrailingZeros().toPlainString());
                }
                break;
            case BOOLEAN:
                targetCell.setCellValue(sourceCell.getBooleanCellValue());
                break;
            case FORMULA:
                targetCell.setCellFormula(sourceCell.getCellFormula());
                break;
            case BLANK:
                targetCell.setBlank();
                break;
            case ERROR:
                targetCell.setCellErrorValue(sourceCell.getErrorCellValue());
                break;
            default:
                break;
        }
    }

    private static void copyPictures(Sheet sourceSheet, Sheet targetSheet, XSSFWorkbook targetWorkbook) {
        XSSFDrawing sourceDrawing = ((XSSFSheet) sourceSheet).getDrawingPatriarch();
        if (sourceDrawing == null) {
            return;
        }

        XSSFDrawing targetDrawing = ((XSSFSheet) targetSheet).createDrawingPatriarch();
        for (XSSFShape shape : sourceDrawing.getShapes()) {
            if (shape instanceof XSSFPicture) {
                XSSFPicture sourcePicture = (XSSFPicture) shape;
                XSSFClientAnchor sourceAnchor = sourcePicture.getClientAnchor();

                XSSFClientAnchor targetAnchor = new XSSFClientAnchor();
                targetAnchor.setCol1(sourceAnchor.getCol1());
                targetAnchor.setRow1(sourceAnchor.getRow1());
                targetAnchor.setCol2(sourceAnchor.getCol2());
                targetAnchor.setRow2(sourceAnchor.getRow2());
                targetAnchor.setDx1(sourceAnchor.getDx1());
                targetAnchor.setDx2(sourceAnchor.getDx2());
                targetAnchor.setDy1(sourceAnchor.getDy1());
                targetAnchor.setDy2(sourceAnchor.getDy2());

                XSSFPictureData sourcePictureData = sourcePicture.getPictureData();
                int pictureIndex = targetWorkbook.addPicture(
                        sourcePictureData.getData(), sourcePictureData.getPictureType());
                targetDrawing.createPicture(targetAnchor, pictureIndex);
            }
        }
    }

    private static void copyMergedRegions(Sheet sourceSheet, Sheet targetSheet) {
        for (int i = 0; i < sourceSheet.getNumMergedRegions(); i++) {
            targetSheet.addMergedRegion(sourceSheet.getMergedRegion(i));
        }
    }

    /**
     * 【改进 #1-A7】复制列宽时增加空行判断
     */
    private static void copyColumnWidths(Sheet sourceSheet, Sheet targetSheet) {
        Row firstRow = sourceSheet.getRow(0);
        if (firstRow == null) {
            return;
        }
        for (int i = 0; i < firstRow.getLastCellNum(); i++) {
            int columnWidth = sourceSheet.getColumnWidth(i);
            targetSheet.setColumnWidth(i, columnWidth > 0 ? columnWidth : FALLBACK_COLUMN_WIDTH);
        }
    }

    // ==================== 样式缓存 ====================

    /**
     * 【改进 #1-A2】StyleSignature 使用 hashCode + 关键属性组合，避免 hash 碰撞
     */
    static class CellStyleCache {
        private final XSSFWorkbook targetWorkbook;
        private final Map<StyleSignature, XSSFCellStyle> cache = new HashMap<>();

        public CellStyleCache(XSSFWorkbook workbook) {
            this.targetWorkbook = workbook;
        }

        public XSSFCellStyle getOrCreate(XSSFCellStyle sourceStyle) {
            StyleSignature sig = new StyleSignature(sourceStyle);
            return cache.computeIfAbsent(sig, k -> {
                XSSFCellStyle newStyle = targetWorkbook.createCellStyle();
                newStyle.cloneStyleFrom(sourceStyle);
                return newStyle;
            });
        }

        private static class StyleSignature {
            private final int hashCode;
            private final short fontIndex;
            private final short dataFormat;
            private final short alignment;

            public StyleSignature(XSSFCellStyle style) {
                this.hashCode = style.hashCode();
                this.fontIndex = style.getFontIndex();
                this.dataFormat = style.getDataFormat();
                this.alignment = style.getAlignment().getCode();
            }

            @Override
            public boolean equals(Object o) {
                if (this == o) return true;
                if (o == null || getClass() != o.getClass()) return false;
                StyleSignature that = (StyleSignature) o;
                return this.hashCode == that.hashCode
                        && this.fontIndex == that.fontIndex
                        && this.dataFormat == that.dataFormat
                        && this.alignment == that.alignment;
            }

            @Override
            public int hashCode() {
                return hashCode;

        }

    // ==================== 单元格读取工具方法 ====================

    /**
     * 获取单元格 String 类型的值
     */
    public static String getStringCellValue(Cell cell) {
        switch (cell.getCellType()) {
            case NUMERIC:
                if (DateUtil.isCellDateFormatted(cell)) {
                    final ZoneId EAST_8 = ZoneOffset.ofHours(8);
                    LocalDateTime localDateTime = LocalDateTime.ofInstant(
                            DateUtil.getJavaDate(cell.getNumericCellValue()).toInstant(), EAST_8);
                    return localDateTime.toString();
                } else {
                    return new BigDecimal(String.valueOf(cell.getNumericCellValue()))
                            .stripTrailingZeros().toPlainString();
                }
            case STRING:
                return cell.getStringCellValue();
            default:
                return "";
        }
    }

    /**
     * 获取有边框的水平垂直居中的 CellStyle
     */
    public static CellStyle getCellStyleWithBorder(Workbook workbook, HorizontalAlignment ha,
                                                   VerticalAlignment va, short bgColor,
                                                   boolean autoBreakLine, boolean protectedCell) {
        CellStyle style = workbook.createCellStyle();
        style.setFillForegroundColor(bgColor);

        style.setBorderTop(BorderStyle.THIN);
        style.setBorderBottom(BorderStyle.THIN);
        style.setBorderLeft(BorderStyle.THIN);

        style.setTopBorderColor(IndexedColors.BLACK.getIndex());
        style.setBottomBorderColor(IndexedColors.BLACK.getIndex());

        style.setRightBorderColor(IndexedColors.BLACK.getIndex());

        style.setVerticalAlignment(Optional.ofNullable(va).orElse(VerticalAlignment.CENTER));
        style.setWrapText(autoBreakLine);
        style.setLocked(protectedCell);

    }

## 五、改进要点总结

### 改进 #1：7 个 Bug 修复明细

| Bug 编号 | 问题 | V1 表现 | V2 修复方式 |
|---------|------|---------|------------|
| A1 | 类名与构造函数不一致 | `XxBaseException` 文件中构造函数写 `HLBaseException` | 构造函数名统一为 `XxBaseException` |
| A2 | StyleSignature hash 碰撞 | `equals()` 仅比较 `hashCode` | 增加 `fontIndex`/`dataFormat`/`alignment` 联合比较 |
| A3 | 错误码重复 | `003001` 和 `005000` 各被两个枚举项使用 | `USER_HAS_ACTIVATED_ERROR` 改为 `003010`；`CREATE_GLOBAL_SERIAL_NUMBER_FAILED` 改为 `005001` |
| A4 | getMessage 比较逻辑 | `codeConstants.equals(code)` 枚举与 String 比较永远 false | 改为 `constants.getCode().equals(code)` |
| A5 | message 未传 super | `BizException` 和 `XxBaseException` 的 `getMessage()` 返回 null | `XxBaseException` 不再遮蔽 `message`，通过 `super(message)` 传递；移除 `protected String message` 字段和 `getMessage()` 重写 |
| A6 | 文件名无后缀静默返回 | `split.length == 1` 时 `return`，客户端收到空响应 | 改为 `throw new IllegalArgumentException` |
| A7 | copyColumnWidths NPE | `sourceSheet.getRow(0)` 可能为 null | 增加 null 判断 |

### 改进 #2：Workbook 接口升级

V1 核心 API 全部使用 `HSSFWorkbook`/`HSSFSheet`/`HSSFRow`/`HSSFCell`/`HSSFCellStyle`/`HSSFFont`，只能导出 `.xls` 格式（最大 65536 行）。

V2 全部升级为 `Workbook`/`Sheet`/`Row`/`Cell`/`CellStyle`/`Font` 接口。调用方传入 `new HSSFWorkbook()` 得到 xls，传入 `new XSSFWorkbook()` 得到 xlsx——同一套代码支持双格式。

### 改进 #3：fillData 样式智能填充

V1 的 `fillData()` 在回调执行后**强制覆盖所有数据行 Cell 的样式**为 `defaultDataCellStyle`，调用方在 lambda 中设置的自定义样式（如红色标记错误行）会被清除。

V2 改为检查 `cell.getCellStyle().getIndex() == 0`（样式索引为 0 表示未设置自定义样式），仅对未自定义的 Cell 应用默认样式。

### 改进 #5：资源安全 + reset 顺序

V1 的 `export(HttpServletResponse, ...)` 先 `getOutputStream()` 再 `reset()`，若响应已提交则 `reset()` 抛 `IllegalStateException`。且 `workbook` 从未关闭，存在资源泄漏。

V2 修正为：先 `reset()` → 设置 header → `getOutputStream()` → `write()` → `flush()`，并在 `finally` 块中调用 `workbook.close()`。
