     * @param sheetNameToSheetDataMap       sheetName到数据集的映射
     * @param defaultTitleCellStyleFunction 数据单元格样式回调Function，开放配置默认单元格样式
     * @param defaultDataCellStyleFunction  数据单元格样式回调Function，开放配置默认单元格样式
     * @param defaultColumnWidth            默认列宽（单位：字符宽度）
     * @param defaultRowHeight              默认行高（单位：磅）

                                               Function<HSSFWorkbook, HSSFCellStyle> defaultTitleCellStyleFunction,
                                               Function<HSSFWorkbook, HSSFCellStyle> defaultDataCellStyleFunction,
                                               Integer defaultColumnWidth,
                                               Integer defaultRowHeight) {
        List<String> headers = new ArrayList<>(titles);
        ExcelExportUtils<T> thisUtil = new ExcelExportUtils<>();
        thisUtil.sheetNameToSheetMap = new HashMap<>(sheetNameToSheetDataMap.size());
        thisUtil.workbook = new HSSFWorkbook();
        if (defaultTitleCellStyleFunction == null) {
            thisUtil.defaultHeaderCellStyle = thisUtil.getDefaultHeaderCellStyle();
        } else {
            thisUtil.defaultHeaderCellStyle = defaultTitleCellStyleFunction.apply(thisUtil.workbook);
        }
        if (defaultDataCellStyleFunction == null) {
            thisUtil.defaultDataCellStyle = thisUtil.getDefaultDataCellStyle();
        } else {
            thisUtil.defaultDataCellStyle = defaultDataCellStyleFunction.apply(thisUtil.workbook);
        }
        thisUtil.sheetNameToSheetDataMap = sheetNameToSheetDataMap;
        sheetNameToSheetDataMap.keySet().forEach(sheetName -> {
            HSSFSheet sheet = thisUtil.workbook.createSheet(sheetName);
            // 设置列宽（默认12个字符宽度）
            sheet.setDefaultColumnWidth(Optional.ofNullable(defaultColumnWidth).orElse(9));
            // 设置行高（默认17.25磅）
            sheet.setDefaultRowHeight(Optional.ofNullable(defaultRowHeight).orElse((int) (17.25 * 20)).shortValue());
            HSSFRow row = sheet.createRow(0);
            for (int i = 0; i < headers.size(); i++) {
                HSSFCell cell = row.createCell(i);
                cell.setCellValue(headers.get(i));
                cell.setCellStyle(thisUtil.defaultHeaderCellStyle);
            }
            // 数据填充阶段使用
            thisUtil.sheetNameToSheetMap.put(sheetName, sheet);
        });

        return thisUtil;
    }

    /**
     * step 1-2 填充每个Sheet的数据
     *
     * @param sheetDataConsumer 两参数消费者，参数一（sheetName->数据集列表），参数二（sheetName->HSSFSheet实例）
     * @return ExcelExportUtils实例，支持链式调用
     */
    public ExcelExportUtils<T> fillData(@NonNull BiConsumer<Map<String, List<T>>, Map<String, HSSFSheet>> sheetDataConsumer) {
        // 确保Step1-2在Step1-1阶段后执行，此时sheetNameToSheetDataMap表单对应的数据集Map应该已经初始化(非null)
        if (sheetNameToSheetDataMap == null) {
            throw new IllegalStateException("[sheetNameToSheetDataMap] without init, maybe you use a wrong init()?");
        }

        sheetDataConsumer.accept(sheetNameToSheetDataMap, sheetNameToSheetMap);
        // 数据填充后，遍历所有Sheet中第二行开始的单元格，统一样式（仅设置字体类型、颜色与大小）
        // 1.该阶段不会重新赋值行高与列宽，所以可以在sheetDataConsumer中重新设置指定列的宽度与指定行的高度（参考类注释文档2.5）
        for (int sheetIndex = 0; sheetIndex < workbook.getNumberOfSheets(); sheetIndex++) {
            HSSFSheet sheet = workbook.getSheetAt(sheetIndex);
            for (int rowIndex = 1; rowIndex <= sheet.getLastRowNum(); rowIndex++) {
                HSSFRow row = sheet.getRow(rowIndex);
                if (row != null) {
                    for (int cellIndex = 0; cellIndex < row.getLastCellNum(); cellIndex++) {
                        HSSFCell cell = row.getCell(cellIndex);
                        if (cell != null) {
                            cell.setCellStyle(defaultDataCellStyle);
                        }
                    }
                }
            }
        }
        return this;
    }

            servletResponse.reset();
            servletResponse.setContentType("application/vnd.ms-excel");
            servletResponse.setHeader("Content-Disposition", "attachment;filename=" + fileName);
            this.workbook.write(outputStream);
            outputStream.flush();
            outputStream.close();
        } catch (IOException e) {
            log.error(">>>>>>>>|export to HttpServletResponse|failed|exception:{}|<<<<<<<<", e.getMessage(), e);
            throw new BizException(SysRetCodeConstants.FAILED.getCode(), e.getMessage());
        }
    }

    /**
     * step 1-3 写入HttpServletResponse
     * step 2-2 写入HttpServletResponse
     * <pre>
     * 将workbook写入HttpServletResponse，默认开启对文件指定URL编码
     * </pre>
     *
     * @param servletResponse HttpServletResponse
     * @param fileName        文件名（默认：template.xls），参数需要指定文件后缀
     */
    public void export(@NonNull HttpServletResponse servletResponse, String fileName) {
        if (StringUtils.isEmpty(fileName)) {
            fileName = "template.xls";
        }
        try {
            String[] split = fileName.split("\\.");
            if (split.length == 1) return;
            fileName = URLEncoder.encode(split[0], StandardCharsets.UTF_8.name()) + "." + split[1];
            OutputStream outputStream = servletResponse.getOutputStream();
            servletResponse.reset();
            servletResponse.setContentType("application/vnd.ms-excel");
            // 2003/excel: application/vnd.ms-excel
            // 2007/excel: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
            servletResponse.setHeader("Content-Disposition", "attachment;filename=" + fileName);
            this.workbook.write(outputStream);
            outputStream.flush();
            outputStream.close();
        } catch (IOException e) {
            log.error(">>>>>>>>|export to HttpServletResponse|failed|exception:{}|<<<<<<<<", e.getMessage(), e);
            throw new BizException(SysRetCodeConstants.FAILED.getCode(), e.getMessage());
        }
    }

    /**
     * 将一个源Sheet完整复制到目标Workbook的新Sheet中， 保留所有内容、样式、图片
     *
     * @param sourceSheet 源Sheet
     * @param targetWorkbook 目标Workbook
     * @param newSheetName 新Sheet的名称
     */
    public static void copySheet(Sheet sourceSheet, XSSFWorkbook targetWorkbook, String newSheetName) {
        XSSFSheet targetSheet = targetWorkbook.createSheet(newSheetName);

        // 创建样式缓存（基于源 workbook 的样式）
        CellStyleCache styleCache = new CellStyleCache(targetWorkbook);

        // --- 1. 复制图片 (必须在复制行列之前进行，因为图片锚点依赖于行列位置) ---
        copyPictures(sourceSheet, targetSheet, targetWorkbook);

        // --- 2. 复制合并单元格 ---
        copyMergedRegions(sourceSheet, targetSheet);

        // --- 3. 精确复制列宽 ---
        copyColumnWidths(sourceSheet, targetSheet);

        // --- 4. 复制行及行内所有单元格 ---
        for (int i = sourceSheet.getFirstRowNum(); i <= sourceSheet.getLastRowNum(); i++) {
            Row sourceRow = sourceSheet.getRow(i);
            if (sourceRow == null) {
                continue;
            }
            // 在目标Sheet创建新行
            Row targetRow = targetSheet.createRow(i);
            // 精确复制行高
            targetRow.setHeight(sourceRow.getHeight());

            // 复制该行内的所有单元格
            for (int j = sourceRow.getFirstCellNum(); j < sourceRow.getLastCellNum(); j++) {
                Cell sourceCell = sourceRow.getCell(j);
                if (sourceCell == null) {
                    continue;
                }
                Cell targetCell = targetRow.createCell(j);
                copyCell(sourceCell, targetCell, styleCache);
            }
        }
    }

    /**
     * 精确复制单个单元格，包括值、样式和数据类型
     *
     * @param sourceCell 源单元格
     * @param targetCell 目标单元格
     */
    private static void copyCell(Cell sourceCell,
                                 Cell targetCell,
                                 CellStyleCache styleCache) {
        // --- 1. 复制单元格样式 ---
        // 使用缓存获取克隆后的样式（避免style.xml压缩率过高导致Zip bomb!）
        if (sourceCell.getCellStyle() != null) {
            CellStyle cachedStyle = styleCache.getOrCreate((XSSFCellStyle) sourceCell.getCellStyle());
            targetCell.setCellStyle(cachedStyle);
        }

        // --- 2. 根据数据类型复制值 ---
        switch (sourceCell.getCellType()) {
            case STRING:
                // 直接复用原有的 RichTextString 对象
                // 它保存了多段文本及其字体、颜色、大小、粗体、斜体、下划线等信息
                targetCell.setCellValue(sourceCell.getRichStringCellValue());
                break;
            case NUMERIC:
                // 处理日期类型
                if (DateUtil.isCellDateFormatted(sourceCell)) {
                    targetCell.setCellValue(sourceCell.getDateCellValue());
                } else {
                    //targetCell.setCellValue(sourceCell.getNumericCellValue());
                    targetCell.setCellValue(new BigDecimal(String.valueOf(sourceCell.getNumericCellValue())).stripTrailingZeros().toPlainString());
                }
                break;
            case BOOLEAN:
                targetCell.setCellValue(sourceCell.getBooleanCellValue());
                break;
            case FORMULA:
                // 复制公式本身，而不是计算结果
                targetCell.setCellFormula(sourceCell.getCellFormula());
                break;
            case BLANK:
                targetCell.setBlank();
                break;
            case ERROR:
                targetCell.setCellErrorValue(sourceCell.getErrorCellValue());
                break;
            default:
                break;
        }
    }

    /**
     * 复制源Sheet中的所有图片到目标Sheet
     * 图片以"绘图"形式存在，需要通过锚点(ClientAnchor)精确控制位置
     */
    private static void copyPictures(Sheet sourceSheet, Sheet targetSheet, XSSFWorkbook targetWorkbook) {
        XSSFDrawing sourceDrawing = ((XSSFSheet) sourceSheet).getDrawingPatriarch();
        if (sourceDrawing == null) {
            return;
        }

        XSSFDrawing targetDrawing = ((XSSFSheet) targetSheet).createDrawingPatriarch();
        for (XSSFShape shape : sourceDrawing.getShapes()) {
            if (shape instanceof XSSFPicture) {
                XSSFPicture sourcePicture = (XSSFPicture) shape;
                XSSFClientAnchor sourceAnchor = sourcePicture.getClientAnchor();

                // 创建新的锚点并复制位置信息，保证图片在新Sheet中的位置与原图一致
                XSSFClientAnchor targetAnchor = new XSSFClientAnchor();
                targetAnchor.setCol1(sourceAnchor.getCol1());
                targetAnchor.setRow1(sourceAnchor.getRow1());
                targetAnchor.setCol2(sourceAnchor.getCol2());
                targetAnchor.setRow2(sourceAnchor.getRow2());
                targetAnchor.setDx1(sourceAnchor.getDx1());
                targetAnchor.setDx2(sourceAnchor.getDx2());
                targetAnchor.setDy1(sourceAnchor.getDy1());
                targetAnchor.setDy2(sourceAnchor.getDy2());

                // 获取原始图片数据，并将其添加到目标Workbook中，获取新的图片索引
                XSSFPictureData sourcePictureData = sourcePicture.getPictureData();
                int pictureIndex = targetWorkbook.addPicture(sourcePictureData.getData(), sourcePictureData.getPictureType());

                // 在目标绘图层创建图片
                targetDrawing.createPicture(targetAnchor, pictureIndex);
            }
        }
    }

    /**
     * 复制合并单元格区域
     */
    private static void copyMergedRegions(Sheet sourceSheet, Sheet targetSheet) {
        for (int i = 0; i < sourceSheet.getNumMergedRegions(); i++) {
            CellRangeAddress mergedRegion = sourceSheet.getMergedRegion(i);
            targetSheet.addMergedRegion(mergedRegion);
        }
    }

    /**
     * 精确复制源Sheet的列宽
     */
    private static void copyColumnWidths(Sheet sourceSheet, Sheet targetSheet) {
        for (int i = 0; i < sourceSheet.getRow(0).getLastCellNum(); i++) {
            int columnWidth = sourceSheet.getColumnWidth(i);
            targetSheet.setColumnWidth(i, columnWidth > 0 ? columnWidth : 2048); // 如果宽度为0，设置一个默认值
        }
    }

    // ========================================================
    // CellStyle样式缓存实现（基于 XSSFCellStyle.cloneStyleFrom）
    // ========================================================
    static class CellStyleCache {
        private final XSSFWorkbook targetWorkbook;
        private final Map<StyleSignature, XSSFCellStyle> cache = new HashMap<>();

        public CellStyleCache(XSSFWorkbook workbook) {
            this.targetWorkbook = workbook;
        }

        public XSSFCellStyle getOrCreate(XSSFCellStyle sourceStyle) {
            StyleSignature sig = new StyleSignature(sourceStyle);
            return cache.computeIfAbsent(sig, k -> {
                XSSFCellStyle newStyle = targetWorkbook.createCellStyle();
                newStyle.cloneStyleFrom(sourceStyle); // 关键：克隆属性
                return newStyle;
            });
        }

        private static class StyleSignature {
            private final int hashCode;

            public StyleSignature(XSSFCellStyle style) {
                this.hashCode = style.hashCode();
            }

            @Override
            public boolean equals(Object o) {
                if (this == o) return true;
                if (o == null || getClass() != o.getClass()) return false;
                StyleSignature that = (StyleSignature) o;
                return this.hashCode == that.hashCode;
            }

            @Override
            public int hashCode() {
                return hashCode;
            }
        }
    }

    /**
     * 获取单元格String类型的值
     *
     * @param cell Cell
     * @return 单元格String类型的值
     */
    public static String getStringCellValue(Cell cell) {
        String result;
        switch (cell.getCellType()) {
            // 数值类型单元格
            case NUMERIC:
                if (DateUtil.isCellDateFormatted(cell)) {
                    // 时间解析
                    // 1.当前版本对导入excel的时间格式进行硬性限制：可自定义但必须被excel中解析为时间（yyyy/mm/dd hh:mm:ss.000）=> 暂不支持文本格式的时间解析
                    // 2.将按照时区(东8区)解析为LocalDateTime
                    final ZoneId EAST_8 = ZoneOffset.ofHours(8);
                    LocalDateTime localDateTime = LocalDateTime.ofInstant(DateUtil.getJavaDate(cell.getNumericCellValue()).toInstant(), EAST_8);
                    result = localDateTime.toString();
                } else {
                    BigDecimal data = new BigDecimal(String.valueOf(cell.getNumericCellValue())).stripTrailingZeros();
                    result = data.stripTrailingZeros().toPlainString();
                }
                break;
            // 文本类型单元格
            case STRING:
                result = cell.getStringCellValue();
                break;
            default:
                result = "";
                break;
        }
        return result;
    }

## 五、深度分析

### 5.1 核心设计思想

#### 1. 三阶段链式 API（Builder 变体）

```
init()  →  fillData()  →  export()
  创建wb       填充数据        输出流
  创建sheet    设置行/列        写response
  写表头       写单元格值
```

这个设计**非常实用**——把 Excel 导出的“创建-填充-输出”三步解耦，调用方只需关心「表头是什么、数据怎么填、输出到哪里」，中间过程由工具类托管。链式调用写法简洁。

#### 2. 回调式数据填充

`fillData(BiConsumer<Map<String, List<T>>, Map<String, HSSFSheet>>)` 的设计很巧妙——同时把「数据 Map」和「Sheet Map」交给调用方，调用方在 lambda 里自行遍历数据、创建 Row/Cell。这比硬编码反射映射灵活得多，适合字段映射复杂的业务场景。

#### 3. 默认样式托管 + 可选覆盖

工具类内置了默认的表头样式（灰底、黑边框、微软雅黑）和数据行样式（黑边框、微软雅黑），同时通过 `Function<HSSFWorkbook, HSSFCellStyle>` 回调开放样式自定义。大多数场景不用管样式，特殊场景可以完全接管。

#### 4. Sheet 复制的完整性保障

`copySheet()` 方法处理了跨 Workbook 复制 Sheet 的完整链路：图片锚点 → 合并区域 → 列宽 → 行/单元格值/样式。配合 `CellStyleCache` 避免重复创建样式对象（防止 xlsx 内部 XML 膨胀导致 Zip Bomb 误报）。

#### 5. 异常体系统一

`XxBaseException` → `BizException` → 工具类中 `throw new BizException(code, message)`，导出失败时统一走业务异常通道，前端可以拿到错误码和消息做提示。

### 5.2 解决的核心问题

| 问题 | 解决方式 |
|------|----------|
| 原生 POI 导出代码冗长（创建 wb/sheet/row/cell/style 至少 30 行） | `init()` 一步完成 wb + sheet + 表头 + 默认样式 |
| 多 Sheet 导出需要手动管理 Sheet 顺序和数据映射 | `LinkedHashMap<String, List<T>>` 统一管控 |
| 样式配置重复 | 默认样式内置 + Function 回调可选覆盖 |
| 导入反馈文件（错误 Sheet 带错误原因） | 每个 Sheet 可单独配置标题（`Map<String, List<String>>` 重载） |
| 跨 Workbook 复制 Sheet（模板场景） | `copySheet()` 完整复制图片/合并/样式/值 |
| 文件名中文乱码 | `URLEncoder.encode()` 默认开启 |

### 5.3 架构设计

```
ExcelExportUtils<T>
├── 静态工厂 init() × 6 个重载
│   ├── List<String> titles + Map data          → 统一表头 + 多Sheet数据
│   ├── Map<String, List<String>> + Map data     → 每Sheet独立表头 + 数据
│   ├── Map<String, List<String>> only           → 纯模板（无数据）
│   └── 以上 3 种 × 是否带样式/行高/列宽回调      → FULL 版本
├── 实例方法 fillData(BiConsumer)                → 数据填充 + 自动刷样式
├── 实例方法 export() × 3 个重载
│   ├── export(HttpServletResponse, fileName)    → 写 HTTP 响应
│   ├── export(HttpServletResponse, fileName, encodeFlag) → @Deprecated
│   └── export(OutputStream)                     → 写通用输出流
├── 静态方法 copySheet()                         → 跨wb复制Sheet
├── 静态方法 getStringCellValue(Cell)            → 读取单元格值
├── 静态方法 getCellStyleWithBorder/WithoutBorder → 快速创建样式
└── 内部类 CellStyleCache                        → 样式缓存
```

### 5.4 存在的问题与待改进点

#### A 类：Bug 级问题（会导致运行时错误或不正确行为）

**A1. `XxBaseException` 类名与构造函数名不一致**

XxBaseException.java 文件名是 `XxBaseException`，但构造函数全部写的 `BiliBaseException`（第 28-63 行）。这说明从 `BiliBaseException` 重命名过来没改干净，**编译不过**。

**A2. `StyleSignature` 仅用 hashCode 做相等判断**

`CellStyleCache` 的 `StyleSignature.equals()` 只比较 `hashCode`，hash 碰撞会导致完全不同的样式被错误复用。应该同时比较关键样式属性，或直接使用 `XSSFCellStyle` 的引用作为 key。

**A3. `SysRetCodeConstants` 错误码重复**

- `USER_OR_PASSWORD_ERROR` = `"003001"` 与 `USER_HAS_ACTIVATED_ERROR` = `"003001"` 重复
- `CREATE_GLOBAL_SERIAL_NUMBER_FAILED` = `"005000"` 与 `SYSTEM_LOAD_DB_CONFIG_EMPTY` = `"005000"` 重复

错误码重复会导致排查问题时定位到错误的枚举项。

**A4. `SysRetCodeConstants.getMessage(String)` 比较逻辑错误**

第 110 行：`codeConstants.equals(code)` 比较的是枚举对象和 String，永远返回 false，这个方法**永远返回 null**。应改为 `codeConstants.getCode().equals(code)`。

**A5. `BizException` 未将 message 传递给 super**

BizException 的构造函数 `super()` 调用后单独设置 `this.message`，但 `Throwable.getMessage()` 返回的是 super 内部的 message 字段，不是 `XxBaseException.message`。导致 `exception.getMessage()` 返回 null。

**A6. 文件名无后缀时静默返回**

第 497 行：`split.length == 1` 时直接 `return`，HTTP 响应没有写入任何内容，客户端收到空响应体。应抛异常或写入默认内容。

**A7. `copyColumnWidths` 未判空**

第 716 行：`sourceSheet.getRow(0)` 如果第 0 行为 null 则 NPE。

#### B 类：设计缺陷（不影响当前运行但存在隐患或限制）

**B1. 锁定 HSSFWorkbook（xls 格式），最大 65536 行**

核心 API 全部使用 `HSSFWorkbook`/`HSSFSheet`/`HSSFRow`/`HSSFCell`，导出的文件是 `.xls` 格式，行数上限 65536。对于大数据量导出场景完全不可用。而 `copySheet` 和 `getCellStyleWithBorder` 又用的是 `XSSFWorkbook`，API 不一致。

**B2. `fillData()` 强制覆盖所有数据行样式**

fillData 回调执行后，遍历所有数据行把所有 Cell 的样式统一刷成 `defaultDataCellStyle`。这意味着**调用方在 lambda 中为特定单元格设置的特殊样式（如红色标记错误行）会被覆盖**。

**B3. `sheetNameToSheetMap` 使用 HashMap 不保序**

虽然 Javadoc 建议用 `LinkedHashMap` 传入数据以保证 Sheet 顺序，但内部 `sheetNameToSheetMap` 用的是 `HashMap`，fillData 回调中拿到的 sheetMap 顺序不可靠。

**B4. Workbook 资源未关闭**

所有 `export()` 方法写完 workbook 后都没有 `workbook.close()`，HSSFWorkbook/XSSFWorkbook 内部持有的流可能泄漏。

**B5. `servletResponse.reset()` 在 `getOutputStream()` 之后调用**

先 `getOutputStream()` 再 `reset()`，如果响应已经提交，`reset()` 会抛 `IllegalStateException`。应该先 reset 再获取流。

**B6. `XxBaseException` 遮蔽了 `Throwable.message`**

XxBaseException 声明了 `protected String message` 遮蔽了父类 `Throwable.message`，重写了 `getMessage()` 返回自己的字段。但构造函数调用 `super()` 没有传 message，导致 `Throwable` 内部的 message 为 null。这种遮蔽设计容易引发混乱。

**B7. 枚举 setter 破坏不可变性**

`SysRetCodeConstants` 提供了 `setCode()` 和 `setMessage()`，枚举常量应该是不可变的。

#### C 类：代码质量 / 可维护性

**C1. 6 个 `init()` 重载存在大量重复代码**

样式初始化、Workbook 创建、Sheet 创建、表头写入、列宽行高设置——这 5 步在 6 个 init 方法中几乎完全复制粘贴。应抽取私有初始化方法。

**C2. 日志格式使用 `>>>>>>>>|...|<<<<<<<<`**

无意义的装饰字符，增加日志解析难度，对排查问题没有帮助。

**C3. 魔法数字散落**

`17.25 * 20`（行高）、`256`（列宽单位）、`2048`（默认列宽）、`9`（默认列宽字符数）——应抽取为命名常量。

**C4. 文件名 split 逻辑不健壮**

`fileName.split("\\.")` 对 `"report.v2.xls"` 会得到 `["report", "v2", "xls"]`，只取 `[0]` 和 `[length-1]` 拼接会丢失中间部分。

### 5.5 改进方案（待确认）

按优先级排列：

| 编号 | 改进项 | 说明 |
|------|--------|------|
| **1** | 修复 A1-A7 共 7 个 Bug | 类名不一致、hash碰撞、错误码重复、getMessage 比较错误、message 未传 super、静默返回、NPE |
| **2** | 核心 API 升级为 Workbook 接口级别 | 将 `init()` 系列方法从 `HSSFWorkbook` 升级为 `Workbook` 接口，支持 xls/xlsx 双格式；或新增 xlsx 系列 init 重载 |
| **3** | fillData 样式策略改为「仅填充默认样式」 | 不再强制覆盖所有 Cell 样式，改为仅在 Cell 没有自定义样式时才设置默认样式 |
| **4** | sheetNameToSheetMap 改为 LinkedHashMap | 保证 fillData 回调中拿到的 sheetMap 顺序与传入一致 |
| **5** | export() 增加 workbook.close() + 修正 reset 顺序 | 先 reset → 设置 header → getOutputStream → write → flush → finally { workbook.close() } |
| **6** | 抽取 init 公共逻辑消除重复代码 | 抽取 `private void doInit(...)` 方法，6 个 init 重载只做参数适配后调用 doInit |

| **8** | 文件名解析改用 lastIndexOf(".") | 正确处理含多个 `.` 的文件名 |
| **9** | 移除枚举 setter | `SysRetCodeConstants` 的 `setCode()`/`setMessage()` 删除，字段改为 `final` |
| **10** | 日志格式清理 | 去掉 `>>>>>>>>|...|<<<<<<<<` 装饰符，使用标准格式 |
