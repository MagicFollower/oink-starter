# ExcelExportUtils V2 使用说明书

## 一、工具定位

`ExcelExportUtils` 是一个基于 Apache POI 的 Excel 导出链式工具，支持：

- **xls / xlsx** 双格式（HSSFWorkbook / XSSFWorkbook）
- **多 Sheet** 导出，Sheet 顺序可控
- **统一表头** 或 **每 Sheet 独立表头**
- **自定义样式回调**（表头样式、数据行样式）
- **智能样式填充**：不覆盖调用方在 `fillData` 中设置的自定义样式
- **Sheet 完整复制**（含内容、样式、合并区域、图片）
- **HttpServletResponse / OutputStream** 两种导出目标
- 内置资源释放（Workbook 自动 close）

## 二、场景速查（按使用场景组织）

### 场景 1：最简单的导出 — 统一表头 + 单 Sheet + 默认样式

```java
List<String> titles = Arrays.asList("姓名", "年龄", "城市");
Map<String, List<User>> data = new LinkedHashMap<>();
data.put("用户列表", userList);

ExcelExportUtils.init(titles, data)
    .fillData((dataMap, sheetMap) -> {
        Sheet sheet = sheetMap.get("用户列表");
        List<User> list = dataMap.get("用户列表");
        for (int i = 0; i < list.size(); i++) {
            Row row = sheet.createRow(i + 1); // 第 0 行是表头
            row.createCell(0).setCellValue(list.get(i).getName());
            row.createCell(1).setCellValue(list.get(i).getAge());
            row.createCell(2).setCellValue(list.get(i).getCity());
        }
    })
    .export(outputStream);
```

> 默认使用 `HSSFWorkbook`（xls 格式），默认列宽 9、行高 345 twips。

### 场景 2：多 Sheet + 每个 Sheet 独立表头

```java
Map<String, List<String>> titleMap = new LinkedHashMap<>();
titleMap.put("员工", Arrays.asList("姓名", "工号"));
titleMap.put("部门", Arrays.asList("部门名", "负责人"));

Map<String, List<Object>> data = new LinkedHashMap<>();
data.put("员工", employeeList);
data.put("部门", deptList);

ExcelExportUtils.init(titleMap, data)
    .fillData((dataMap, sheetMap) -> {
        // 填充员工 Sheet
        Sheet empSheet = sheetMap.get("员工");
        List<Object> emps = dataMap.get("员工");
        for (int i = 0; i < emps.size(); i++) {
            Row row = empSheet.createRow(i + 1);
            row.createCell(0).setCellValue(((Employee) emps.get(i)).getName());
            row.createCell(1).setCellValue(((Employee) emps.get(i)).getNo());
        }
        // 填充部门 Sheet
        Sheet deptSheet = sheetMap.get("部门");
        // ...同理
    })
    .export(outputStream);
```

> **注意**：`titleMap` 和 `data` 的 key 必须一一对应，且 `size()` 必须相等，否则抛出 `IllegalArgumentException`。

### 场景 3：导出 xlsx 格式 + 自定义样式

```java
ExcelExportUtils.init(titles, data,
        new XSSFWorkbook(),                           // 指定 xlsx
        wb -> {                                       // 表头样式回调
            CellStyle s = wb.createCellStyle();
            s.setFillForegroundColor(IndexedColors.LIGHT_CORNFLOWER_BLUE.getIndex());
            s.setFillPattern(FillPatternType.SOLID_FOREGROUND);
            Font f = wb.createFont();
            f.setBold(true);
            s.setFont(f);
            return s;
        },
        wb -> {                                       // 数据行样式回调
            CellStyle s = wb.createCellStyle();
            s.setBorderTop(BorderStyle.THIN);
            s.setBorderBottom(BorderStyle.THIN);
            // ...
            return s;
        },
        15,    // 默认列宽（字符数）
        400    // 默认行高（twips）
    )
    .fillData(/* ... */)
    .export(outputStream);
```

### 场景 4：纯模板导出（只有表头，无数据）

适用于生成空白模板供用户下载填写：

```java
Map<String, List<String>> headerMap = new LinkedHashMap<>();
headerMap.put("导入模板", Arrays.asList("姓名", "手机号", "部门", "入职日期"));

ExcelExportUtils.init(headerMap)           // 无 data 参数
    .export(outputStream);
```

也可以指定 Workbook 类型：

```java
ExcelExportUtils.init(headerMap, new XSSFWorkbook())  // 生成 xlsx 模板
```

### 场景 5：通过 HttpServletResponse 导出（浏览器下载）

```java
// Controller 中
public void download(HttpServletResponse response) {
    ExcelExportUtils.init(titles, data)
        .fillData(/* ... */)
        .export(response, "用户报表.xls");    // 文件名自动 URL 编码
}
```

内部行为：
- `response.reset()` → `setContentType("application/vnd.ms-excel")` → `setHeader("Content-Disposition", ...)` → `workbook.write(outputStream)` → `workbook.close()`
- 文件名会正确处理含多个 `.` 的情况（使用 `lastIndexOf('.')` 分割）
- 文件名**必须包含后缀**（`.xls` 或 `.xlsx`），否则抛出 `IllegalArgumentException`

### 场景 6：fillData 中设置自定义样式（不被覆盖）

V2 的改进：`fillData` 采用**智能样式填充**，仅对 `cell.getCellStyle().getIndex() == 0`（即未设置自定义样式）的单元格应用默认样式。

> **如何在 fillData 中获取 Workbook 创建样式**：通过 `sheet.getWorkbook()` 可从任意 Sheet 实例反获取当前 Workbook。

```java
util.fillData((dataMap, sheetMap) -> {
    Sheet sheet = sheetMap.get("Sheet1");
    // 通过 sheet.getWorkbook() 获取当前 Workbook，用于创建样式
    Workbook wb = sheet.getWorkbook();
    CellStyle highlightStyle = wb.createCellStyle();
    highlightStyle.setFillForegroundColor(IndexedColors.YELLOW.getIndex());

    for (int i = 0; i < dataList.size(); i++) {
        Row row = sheet.createRow(i + 1);
        Cell cell = row.createCell(0);
        cell.setCellValue(dataList.get(i));

        if (shouldHighlight(dataList.get(i))) {
            cell.setCellStyle(highlightStyle);  // 自定义样式，不会被覆盖
        }
        // 未设置样式的单元格会自动应用默认数据行样式
    }
});
```

### 场景 7：复制 Sheet（跨 Workbook）

适用于基于模板生成多个同结构 Sheet：

```java
XSSFWorkbook sourceWb = new XSSFWorkbook(new FileInputStream("template.xlsx"));
XSSFWorkbook targetWb = new XSSFWorkbook();

Sheet sourceSheet = sourceWb.getSheetAt(0);
ExcelExportUtils.copySheet(sourceSheet, targetWb, "副本1");
ExcelExportUtils.copySheet(sourceSheet, targetWb, "副本2");

// 复制到目标 Workbook 后，可继续用 fillData 等方式填充数据
```

复制保留的内容：
- 单元格值（STRING / NUMERIC / BOOLEAN / FORMULA / BLANK / ERROR）
- 单元格样式（通过 `CellStyleCache` 去重复用）
- 合并区域
- 列宽
- 图片（`XSSFPicture` + `XSSFClientAnchor` 完整复制）

### 场景 8：工具方法

**读取单元格为 String**（兼容多类型）：

```java
Cell cell = row.getCell(0);
String value = ExcelExportUtils.getStringCellValue(cell);
// NUMERIC → 数字转 plain string（去尾零）
// NUMERIC + 日期格式 → LocalDateTime.toString()
// STRING → 原值
// 其他 → ""
```

**获取带边框 / 无边框的居中样式**：

```java
// V2 中 bgColor 参数类型为 short（IndexedColors 索引值）
CellStyle style = ExcelExportUtils.getCellStyleWithBorder(
    workbook,
    HorizontalAlignment.CENTER,    // 水平对齐（null 默认 CENTER）
    VerticalAlignment.CENTER,      // 垂直对齐（null 默认 CENTER）
    IndexedColors.WHITE.getIndex(), // 背景色（short 类型）
    true,                           // 自动换行
    false                           // 是否锁定单元格
);

CellStyle noBorder = ExcelExportUtils.getCellStyleWithoutBorder(
    workbook, null, null, IndexedColors.GREY_25_PERCENT.getIndex(), false, false
);
```

## 三、V1 → V2 迁移指南

| 变更点 | V1 行为 | V2 行为 | 迁移影响 |
|--------|---------|---------|----------|
| **核心 API** | 仅支持 `HSSFWorkbook` | 支持 `Workbook` 接口（HSSF + XSSF） | 无破坏性变更，简单 `init()` 仍默认 `HSSFWorkbook`，新增 xlsx 能力需使用 full 重载 |
| **Sheet 顺序** | `HashMap`，顺序不保证 | `LinkedHashMap`，保序 | 如果你的代码依赖了特定的 Sheet 顺序，需验证 |
| **样式填充** | `fillData` 强制覆盖所有单元格样式 | 仅对 `styleIndex == 0` 的单元格应用默认样式 | 如果 V1 中依赖"全覆盖"行为来重置样式，V2 中需手动处理 |
| **资源释放** | 无 `workbook.close()` | `export()` 的 `finally` 块中自动 close | 无需手动 close，但如果 export 后还要操作 workbook，会失败 |
| **reset 顺序** | 先获取流再 reset | 先 reset 再获取流 | 修复了潜在的响应缓冲问题，无迁移成本 |
| **文件名解析** | `split(".")` | `lastIndexOf('.')` | 含多个 `.` 的文件名（如 `v2.0.report.xlsx`）现在能正确处理 |
| **无后缀文件名** | 静默返回（客户端收到空响应） | 抛出 `IllegalArgumentException` | **破坏性变更**：如果传入了无后缀文件名，V2 会抛异常 |
| **fillData 空数据** | 静默跳过 | 抛出 `IllegalStateException` | **破坏性变更**：纯模板模式误调 `fillData` 会报错 |
| **异常类型** | `BizException` 包装 | 仍为 `BizException`（`SysRetCodeConstants.FAILED`） | 无变化 |
| **魔法数字** | 代码中散布 `9`、`345`、`256` 等 | 抽取为命名常量 | 无行为变化，代码可读性提升 |

### 迁移检查清单

- [ ] 确认所有 `init()` 调用的 `titleMap` 和 `dataMap` 的 key 数量一致
- [ ] 确认传入的文件名都包含后缀（`.xls` / `.xlsx`）
- [ ] 确认没有在 `export()` 之后继续操作 workbook
- [ ] 如果在 `fillData` 中设置了自定义样式，验证 V2 的智能填充不会导致样式丢失
- [ ] 如果依赖 Sheet 顺序，验证 V2 的 `LinkedHashMap` 保序行为是否符合预期

## 四、异常速查

| 异常类型 | 触发条件 | 解决方案 |
|----------|----------|----------|
| `IllegalArgumentException` | `init()` 时 titleMap 与 dataMap 大小不一致 | 检查两个 Map 的 key 是否完全对应 |
| `IllegalArgumentException` | `export()` 文件名无后缀 | 确保文件名包含 `.xls` 或 `.xlsx` |
| `IllegalStateException` | 纯模板模式（无 data）下调 `fillData()` | 纯模板不要调 `fillData`，直接 `export` |
| `BizException` | `export()` 写流时发生 `IOException` | 检查输出流是否可用、响应是否已提交 |

---

## 五、注意事项

1. **链式调用顺序**：`init()` → `fillData()` → `export()`，不可颠倒或跳过。
2. **export 后不可复用**：`export()` 的 `finally` 块会关闭 workbook，之后不能再操作该实例。
3. **fillData 中行号从 1 开始**：第 0 行是表头，数据行从 `sheet.createRow(i + 1)` 开始。
4. **样式智能填充的判定条件**：`cell.getCellStyle().getIndex() == 0` 表示"未设置自定义样式"。如果你在 `fillData` 中创建了新的 `CellStyle` 并赋给了单元格，它不会被默认样式覆盖。
5. **fillData 中获取 Workbook**：通过 `sheet.getWorkbook()` 可从 `sheetMap` 中任意 Sheet 反获取当前 Workbook 实例，用于创建自定义 `CellStyle`。
6. **copySheet 要求源 Sheet 来自 XSSFWorkbook**：`copySheet` 内部使用了 `XSSFSheet` 的 API（如 `getDrawingPatriarch()`），源 Sheet 必须是 xlsx 格式。
7. **默认列宽/行高常量**：列宽 `9`（字符数）、行高 `345`（twips，即 17.25 磅），可通过 `init()` 的参数覆盖。
8. **线程安全**：`ExcelExportUtils` 实例**非线程安全**，每次导出应创建新实例。静态方法（`copySheet`、`getStringCellValue`、`getCellStyleWithBorder`/`WithoutBorder`）本身是线程安全的，但传入的 Workbook 对象由调用方保证线程安全。
