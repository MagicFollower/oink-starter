# ExcelImportParserV2 使用说明书

## 一、工具定位

`ExcelImportParserV2` 是 `ExcelImportParser` 的架构优化版本，核心改进是引入 **RowAccessor** 封装行级数据访问。

**V2 相比 V1 的改进：**

| 维度 | V1 | V2 |
|------|----|----|
| mapper 签名 | `map(rowIndex, cellList, titleMap)` | `map(rowIndex, row)` |
| 取值方式 | `ExcelImportParser.getCellStr(cellList, titleMap, "列名")` | `row.getString("列名")` |
| 返回类型 | 只有 String | String / Integer / Long / BigDecimal / Object |
| 参数传递 | 每次调用传 3 个参数 | 传 1 个参数（列名或索引） |
| 按索引取值 | `cellList.get(index).toString().trim()` | `row.getStringAt(index)` |
| 原始值访问 | `cellList.get(index)` | `row.getRaw("列名")` / `row.getRawAt(index)` |

**保留 V1 的全部能力：**

- **表头自动校验** — 在 `headerRowIndex`（默认第 0 行）处与 `expectedTitles` 逐列 trim 比较
- **空行自动跳过** — 所有单元格为 null/空白 的行不进入 mapper
- **单元格自动补齐** — cellList 长度不足时用空串补齐，null 元素替换为空串
- **异常统一包装** — `BizException` 透传，其他异常包装为 `BizException`
- **可配置** — sheetIndex、headerRowIndex、validateHeader、dataStartRow 等灵活配置

### 场景 1：最基本的导入解析

```java
List<String> titles = Arrays.asList("姓名", "年龄", "城市");

List<MyVO> result = ExcelImportParserV2.<MyVO>builder()
    .inputStream(multipartFile.getInputStream())
    .expectedTitles(titles)
    .mapper((rowIndex, row) -> {
        MyVO vo = new MyVO();
        vo.setName(row.getString("姓名"));
        vo.setAge(row.getString("年龄"));
        vo.setCity(row.getString("城市"));
        return vo;
    })
    .parse();
```

> 默认行为：解析第 0 个 Sheet、校验表头、从第 1 行开始解析数据。

```java
@PostMapping("/import")
public Result importExcel(@RequestParam("file") MultipartFile file) {
    Result rp = new Result();
    List<String> titles = Arrays.asList("订单单号", "订单类型", "备件编码", "备件名称");

        List<OrderImportVO> list = ExcelImportParserV2.<OrderImportVO>builder()
```

### 场景 7：处理数值类型（V2 核心优势）

V2 的 `RowAccessor` 直接支持数值类型转换，无需手动处理 `"25.0"` 这种 Double toString 问题：

```java
ExcelImportParserV2.<OrderVO>builder()
    .inputStream(inputStream)
    .expectedTitles(Arrays.asList("商品名称", "数量", "金额", "单价"))
    .mapper((rowIndex, row) -> {
        OrderVO vo = new OrderVO();
        vo.setName(row.getString("商品名称"));        // String
        vo.setQuantity(row.getInteger("数量"));        // Integer（自动处理 "100.0"）
        vo.setAmount(row.getLong("金额"));             // Long
        vo.setPrice(row.getDecimal("单价"));           // BigDecimal
        return vo;
    })
    .parse();
```

> **V2 新增**：`getInteger` / `getLong` / `getDecimal` 自动处理 SAX 模式下数值单元格产生的 `"25.0"` 格式，通过 `BigDecimal` 中转确保精度。空值或格式错误返回 `null`。

## 三、API 速查

### Builder 配置方法

| 方法 | 默认值 | 说明 |
|------|--------|------|
| `.inputStream(InputStream)` | **必填** | Excel 文件输入流 |
| `.expectedTitles(List<String>)` | **必填** | 期望的列名列表，用于表头校验和构建 titleIndexMap |
| `.mapper(RowMapper<T>)` | **必填** | 行数据映射函数 |
| `.sheetIndex(int)` | `0` | 要解析的 Sheet 索引（0-based） |
| `.headerRowIndex(long)` | `0` | 表头行号（0-based），该行用于表头校验 |
| `.validateHeader(boolean)` | `true` | 是否校验表头行与 expectedTitles 匹配 |
| `.dataStartRow(long)` | `1` | 数据起始行号（0-based），之前的行会被跳过 |

### RowMapper 函数式接口

```java
@FunctionalInterface
public interface RowMapper<T> {
    T map(long rowIndex, RowAccessor row);
}
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `rowIndex` | `long` | 当前行号（0-based） |
| `row` | `RowAccessor` | 行数据访问器，封装了 cellList 和 titleIndexMap |

### RowAccessor 方法速查

**按列名取值：**

| 方法 | 返回类型 | 空值/不存在时 |
|------|---------|--------------|
| `getString(columnName)` | `String` | `""` |
| `getInteger(columnName)` | `Integer` | `null` |
| `getLong(columnName)` | `Long` | `null` |
| `getDecimal(columnName)` | `BigDecimal` | `null` |
| `getRaw(columnName)` | `Object` | `null` |

**按索引取值：**

| 方法 | 返回类型 | 越界时 |
|------|---------|--------|
| `getStringAt(index)` | `String` | `""` |
| `getIntegerAt(index)` | `Integer` | `null` |
| `getLongAt(index)` | `Long` | `null` |
| `getDecimalAt(index)` | `BigDecimal` | `null` |
| `getRawAt(index)` | `Object` | `null` |

**底层访问：**

| 方法 | 返回类型 | 说明 |
|------|---------|------|
| `getCellList()` | `List<Object>` | 当前行的单元格列表（已补齐） |
| `getTitleIndexMap()` | `Map<String, Integer>` | 列名→索引映射 |

## 四、异常速查

| 异常类型 | 触发条件 | 解决方案 |
|----------|----------|----------|
| `IllegalArgumentException` | `inputStream` 为 null | 确保传入有效的 InputStream |
| `IllegalArgumentException` | `expectedTitles` 为 null 或空 | 至少提供一列期望标题 |
| `IllegalArgumentException` | `mapper` 为 null | 必须提供 RowMapper |
| `BizException` | 表头校验失败（`validateHeader=true` 时） | 检查 Excel 文件表头是否与 expectedTitles 一致 |
| `BizException` | 文件解析异常（IO 异常、格式错误等） | 确保文件完整且未被加密 |

> 表头校验失败的错误信息格式：`文件解析异常:标题行不匹配(解析列[期望列名],excel中对应列为[实际列名])!`

## 五、内置行为详解

### 表头校验

- 发生在 `rowIndex == headerRowIndex` 时（`headerRowIndex` 默认为 0）
- 逐列 trim 后比较，忽略前后空格
- 如果 Excel 实际列数少于 expectedTitles，缺失列视为空串，与期望不匹配
- 如果 Excel 实际列数多于 expectedTitles，多余列被忽略（不报错）
- 校验失败抛出 `BizException`，不会继续解析后续行

### 空行跳过

- 判定标准：cellList 中所有元素均为 null 或空白字符串
- 空行不进入 mapper，不加入结果列表
- 空行判断发生在单元格补齐之前

### 单元格补齐

- 发生在空行判断之后
- null 元素替换为 `""`（空串）
- cellList 长度不足 expectedTitles.size() 时，末尾补 `""`
- 补齐后 cellList 长度 >= expectedTitles.size()

### 异常处理

- `BizException`（包括表头校验失败）直接透传
- 其他所有异常被包装为 `BizException`，错误码为 `SysRetCodeConstants.FAILED`，消息为 `"文件解析异常，请确保文件完整且未被加密: {原始消息}"`

### 数值类型转换

- `getInteger` / `getLong` / `getDecimal` 通过 `BigDecimal` 中转，自动处理 `"25.0"` 格式
- 转换失败（非数字字符串）返回 `null`，不抛异常
- 空字符串返回 `null`

## 六、V1 → V2 迁移指南

### 代码变更

| V1 写法 | V2 写法 |
|---------|---------|
| `ExcelImportParser.getCellStr(cellList, titleMap, "列名")` | `row.getString("列名")` |
| `cellList.get(0).toString().trim()` | `row.getStringAt(0)` |
| `cellList.get(index)` 手动转 Integer | `row.getInteger("列名")` |
| `cellList.get(index)` 手动转 BigDecimal | `row.getDecimal("列名")` |
| `map(rowIndex, cellList, titleMap)` | `map(rowIndex, row)` |

### 迁移步骤

1. 将 `ExcelImportParser` 替换为 `ExcelImportParserV2`
2. 将 mapper 签名从 `(rowIndex, cellList, titleMap)` 改为 `(rowIndex, row)`
3. 将所有 `ExcelImportParser.getCellStr(cellList, titleMap, "xxx")` 替换为 `row.getString("xxx")`
4. （可选）将手动数值转换替换为 `row.getInteger()` / `row.getDecimal()`

### 注意事项

- V2 与 V1 **不兼容**：`RowMapper` 签名不同，不能直接替换类名
- V2 保留了 V1 的全部内置行为（表头校验、空行跳过、单元格补齐、异常包装）
- V2 的 `RowAccessor` 每次 mapper 调用时创建新实例，不是线程安全的（但 mapper 本身在单线程中执行）

### 原始代码（79 行）

```java
List<CurCcaPoImportVO> importVOList = new ArrayList<>();
List<String> excelTitlesCommon = ListUtil.of(
        "订单单号", "订单类型", "备件编码", "备件名称", "备件件号",
        "销售数量", "订单明细备注", "型号", "接收单位", "接收地址",
        "接收人", "联系电话", "备注", "ERP订单", "状态");
try {
    ExcelUtil.readBySax(multipartFile.getInputStream(), 0, new RowHandler() {
        @Override
        public void handle(int sheetIndex, long rowIndex, List<Object> cellList) {
            if (rowIndex == 0) {
                List<String> excelTitlesInExcel = cellList.stream()
                    .filter(Objects::nonNull).map(Object::toString).collect(Collectors.toList());
                for (int i = 0; i < excelTitlesCommon.size(); i++) {
                    String trimmedX = StrUtil.trim(excelTitlesCommon.get(i));
                    String trimmedY = StrUtil.trim(excelTitlesInExcel.get(i));
                    if (!StrUtil.equals(trimmedX, trimmedY)) {
                        throw new BizException(SysRetCodeConstants.FAILED.getCode(),
                            String.format("文件解析异常:标题行不匹配(解析列[%s],excel中对应列为[%s])!",
                                trimmedX, trimmedY));
                    }
                }
            }
            if (rowIndex >= 1) {
                if (cellList.stream().anyMatch(x -> !StringUtils.isEmpty(x))) {
                    fillListWithEmptyStr(cellList, excelTitlesCommon.size());
                    CurCcaPoImportVO importVO = new CurCcaPoImportVO();
                    importVO.setBillNo(cellList.get(0).toString().trim());
                    importVO.setCcaPoType(cellList.get(1).toString().trim());
                    importVO.setIsBack(false);
                    importVO.setCcaGoodsCode(cellList.get(2).toString().trim());
                    importVO.setCcaGoodsName(cellList.get(3).toString().trim());
                    importVO.setCcaGoodsNo(cellList.get(4).toString().trim());
                    importVO.setPoQty(cellList.get(5).toString().trim());
                    importVO.setPoMemo(cellList.get(6).toString().trim());
                    importVO.setCcaGoodsSpecdesc(cellList.get(7).toString().trim());
                    importVO.setReceiveCustname(cellList.get(8).toString().trim());
                    importVO.setReceiveAddr(cellList.get(9).toString().trim());
                    importVO.setReceiveName(cellList.get(10).toString().trim());
                    importVO.setReceiveTel(cellList.get(11).toString().trim());
                    importVO.setMemo(cellList.get(12).toString().trim());
                    importVO.setErpOrder_(cellList.get(13).toString().trim());
                    importVO.setStatus_(cellList.get(14).toString().trim());
                    importVOList.add(importVO);
                }
            }
        }
        private void fillListWithEmptyStr(final List<Object> rowCells, final int count) {
            final int tmpSize = rowCells.size();
            if (tmpSize < count) {
                for (int i = 0; i < count - tmpSize; i++) {
                    rowCells.add(StrUtil.EMPTY);
                }
            }
            for (int i = 0; i < rowCells.size(); i++) {
                if (rowCells.get(i) == null) {
                    rowCells.set(i, StrUtil.EMPTY);
                }
            }
        }
    });
} catch (BizException e) {
    LOGGER.error(">>>>>>>>|CurCcaPo importExcel|BizException|文件解析异常:{}|<<<<<<<<",
        e.getMessage(), e);
    return rp.setErrorMsg(e.getErrorCode(), e.getMessage());
} catch (Exception e) {
    LOGGER.error(">>>>>>>>|CurCcaPo importExcel|Exception|文件解析异常，请确保文件完整且未被加密:{}|<<<<<<<<",
        e.getMessage(), e);
    return rp.setErrorMsg(SysRetCodeConstants.FAILED.getCode(),
        "文件解析异常，请确保文件完整且未被加密");
```

## 八、注意事项

1. **调用顺序**：`builder()` → 配置方法 → `parse()`，`parse()` 执行后 InputStream 被消费，不可重复使用。
2. **数值转换**：`getInteger` / `getLong` / `getDecimal` 通过 `BigDecimal` 中转处理 `"25.0"` 格式。转换失败返回 `null`，不抛异常。如需区分"空值"和"格式错误"，请使用 `getRaw` 自行判断。
3. **RowAccessor 生命周期**：每次 mapper 调用时创建新的 RowAccessor 实例，mapper 返回后该实例可被 GC 回收。不要在 mapper 外部持有 row 引用。
4. **titleIndexMap 基于 expectedTitles**：不是基于 Excel 实际表头。如果关闭了表头校验且 Excel 列顺序与 expectedTitles 不同，`getString("列名")` 会取到错误数据。
5. **mapper 返回 null 安全**：mapper 返回 null 时该行被跳过，不会加入结果列表。
6. **线程安全**：`ExcelImportParserV2` 实例不是线程安全的，每次解析应创建新的 builder 实例。
7. **大文件友好**：底层使用 Hutool SAX 模式，不会将整个文件加载到内存。
8. **仅支持 xls/xlsx**：底层依赖 Hutool POI，支持 `.xls`（HSSF）和 `.xlsx`（XSSF）格式。
