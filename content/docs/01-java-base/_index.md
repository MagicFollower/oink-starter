Java 基础涵盖语言核心语法与常用 API，是所有进阶学习的起点。

## 知识板块

- **语言语法** — 数据类型、控制流、数组、字符串
- **面向对象** — 类与对象、继承、多态、接口、抽象类、final 修饰符
- **常用工具类** — Optional 空值处理、Objects 工具方法、String 高级操作
- **泛型与反射** — 类型擦除、通配符、注解、动态代理
- **异常处理** — 异常体系、自定义异常、try-with-resources
- **IO 与 NIO** — 文件操作、流、通道、缓冲区、序列化
