深入 JVM 内部机制，理解 Java 程序的底层运行原理。

## 知识板块

- **内存模型** — 堆、栈、方法区、直接内存、JMM
- **垃圾回收** — 回收算法、收集器（G1/ZGC）、GC 调优
- **类加载** — 双亲委派、自定义类加载器、热部署
- **字节码** — 指令集、增强字节码、Instrumentation
- **调优实战** — JVM 参数、诊断工具（jstack/jmap/arthas）、OOM 排查
