本板块系统讲解 Apache Maven 构建工具，从「它是什么」到「日常怎么用」再到「出了问题怎么排查」，七篇文档组成完整学习路径：

```
Maven 是什么 → 项目结构 → pom.xml → 依赖管理 → 仓库体系 → 命令与生命周期 → settings 配置
是什么          怎么放      怎么写     怎么管       从哪拿       怎么跑             怎么配
```

当前 Maven 最新稳定版为 **3.9.16**（要求 JDK 8+），4.0.x 尚在预览阶段（要求 JDK 17+）。本板块所有文档基于 Maven 3.9.x 编写。
