熟悉 Java 开发中常用的工具链与基础设施。

## 知识板块

- **Maven** — 生命周期、依赖管理、多模块、插件开发
- **Gradle** — 构建脚本、Task 定制、性能优化
- **Git** — 分支策略、Rebase、冲突解决、工作流
- **日志框架** — SLF4J、Logback、Log4j2 配置与调优
- **单元测试** — JUnit 5、Mockito、测试策略与最佳实践
- **IDE 技巧** — IntelliJ IDEA 快捷键、调试技巧、代码模板
