## 问题：下拉列表里的「陌生人」

主题的根选择器（侧边栏顶部的下拉卡片）原本列出全站所有顶级栏目。后果是：在博客页面点开下拉，看到的是笔记的 10 个子分类——读者根本不会在这里跳转去笔记。

```text
博客页面 → 下拉卡片 → 博客          ✅ 本区域条目
                   → Java 基础      ❌ 跨区域干扰
                   → 集合框架       ❌
```

## 方案：按当前页面类型过滤

主题的 `root-menu-entries（侧边栏下拉卡片列表选中置顶效果）.html` 负责组装下拉条目。我们不修改主题文件，而是在站点 `layouts/_partials/shell/` 放置同名覆盖文件，加入按 `$page.Type` 过滤的逻辑：

```text
读取当前页面类型 $page.Type
  → blog 页面：只保留博客相关条目
  → docs 页面：保留笔记及其子分类
  → 其他：维持原状
```

## 为什么不改主题

| 做法 | 主题升级时 | 改动可追溯性 |
|------|-----------|------------|
| 直接改主题源码 | 覆盖丢失，需重新合并 | 混在 70+ 模板文件里 |
| 站点目录同名覆盖 | 自动保留 | 集中在站点 layouts/ 下，一目了然 |

> ### 💡 新人小结：Partial 覆盖是什么？
>
> Hugo 找模板时先看站点 `layouts/`，再找主题目录。就像酒店房间自备的一次性拖鞋（主题默认模板），你带上自己的拖鞋（站点同名文件）放在同一位置，服务生永远先递你的。

## 结果

每个区域的下拉列表只显示本区域条目，跨区域跳转交给顶部导航，职责分离。
